# 実データ検証ツール（MATLAB アプリ）

アライメント計測値の面内推定の手法比較を、**実データ（Excel）** で確かめるための画面つきアプリです。
Excel の計測データを読み込み、画面で比べ方を決めて実行し、結果の表・グラフ・Wafer ごとの図を画面で確認します。
推定の計算は、模擬データで評価した Python 版（リポジトリの `src/`）を MATLAB に移したもので、同じ計算結果になることを照合しています（下の「動作確認」）。

- **Windows での使い方・exe の作り方の手順書（HTML）**：[docs/windows_guide/windows_guide.html](docs/windows_guide/windows_guide.html)（ブラウザで開く。画像・CSS が同じフォルダにあるので、フォルダごと扱う）
- 計算部分は **MATLAB 本体だけ** で動きます（Toolbox は不要。依存解析で確認）。
- **スタンドアローン版（Windows の .exe）** は、MATLAB Compiler の入った PC で `build/buildStandaloneApp.m` を実行して作ります。

## 必要な環境

| 用途 | 必要なもの |
| --- | --- |
| MATLAB の中で使う | MATLAB R2022b で動作確認（R2021a 以上を想定）。Toolbox は不要 |
| スタンドアローン版を作る | MATLAB と **MATLAB Compiler**（同じ PC に入っていること） |
| スタンドアローン版を使う | 作ったときと **同じ版の MATLAB Runtime**（無料。インストーラー版を使うと一緒に入る）。MATLAB 本体は不要 |

Excel 本体は不要です（MATLAB の読み込み・書き出し機能を使います）。環境変数・認証情報・外部サービスは使いません。

## 使い方（MATLAB の中で）

1. MATLAB で `matlab_app` フォルダを開く（現在のフォルダにする）。
2. コマンドウィンドウで次を入力する。

   ```matlab
   runAlignmentEstimationApp
   ```

3. 画面のタブを左から順に進める。

| タブ | すること |
| --- | --- |
| 1. データの読み込み | 「ファイルを選ぶ…」で Excel（または CSV）を選ぶ。列の対応・座標の単位・行の除外条件・Scan 方向の付与を確かめて「この対応で読み込む」。中のタブ「Wafer マップ（計測値）」でベクトルと X・Y のヒートマップ、「Shot レイアウト」で Shot の枠・shotNo・Mark の位置と番号を確かめる |
| 2. 評価の設定 | 学習に使う Shot の選び方、学習 Shot 数（開始・終了・刻み）、比べる手法を選ぶ（初期設定は「推奨の組み合わせ」）。必要なら処理時間の記録をオンにする |
| 3. 実行 | 「評価を始める」。進み具合と残り時間が出る。「止める」で途中までの結果を残して止められる |
| 4. 結果一覧 | 手法 × 学習 Shot 数 の表（各列の最良に ★。集計は平均・中央値・ワースト値・95%値）、グラフ（横軸は学習 Shot 数、または I 基準・D 基準）、基準の手法との比較、推定値と誤差の分布（ヒストグラム・正規性検定・ANOVA）。評価結果と推定値をそれぞれ Excel に書き出せる |
| 5. Wafer ごとのマップ | Wafer・学習パターン・手法を選び、計測値・推定値・残差を矢印または色で表示（Shot の枠、色の点の大きさを変えられる） |

動作確認用のサンプルデータ（模擬データ5枚）：[sample_data/sample_alignment.xlsx](sample_data/sample_alignment.xlsx)

## スタンドアローン版の作り方（Windows）

MATLAB Compiler の入った Windows PC で行います（Mac では Windows 用の .exe は作れません）。

1. `matlab_app` フォルダごと Windows PC にコピーする。
2. MATLAB で `matlab_app` フォルダを開き、次を入力する（数分かかる）。

   ```matlab
   addpath build
   buildStandaloneApp                       % .exe だけ作る
   buildStandaloneApp(makeInstaller=true)   % インストーラーも作る（MATLAB Runtime をネットから入れる形）
   buildStandaloneApp(makeInstaller=true, runtimeDelivery="installer")  % Runtime 入りのインストーラー（ネットに出られない PC 用）
   ```

3. `build/output/win64/` に `AlignmentEstimationApp.exe` ができる。使う PC に同じ版の MATLAB Runtime を入れてから起動する
   （インストーラー版なら Runtime も一緒に入る）。

スタンドアローン版は画面だけのアプリとして作ります（コマンド画面は出ません）。設定・結果の保存先は、画面のダイアログで選んだ場所です。

## 読み込むデータの形

1行目が項目名、2行目からデータの表です（Excel のシートを選べます）。項目名は Overlay 計測ルールの
アライメント計測テーブルの標準に合わせます。名前が違う場合は、画面の「列の対応」で選び直せます。

| 項目名 | 意味 | 必須 | 無いとき |
| --- | --- | :---: | --- |
| Operation | 工程名 | 任意 | 空。同じ Wafer でも工程が違えば別の計測として扱う |
| EqpId | 装置 ID | 任意 | 空。同じ Wafer でも装置が違えば別の計測として扱う |
| Wafer | ウェハ ID | 任意 | 全行を1枚とみなす |
| DateTime | 測定日時 | 任意 | 空。同じ Wafer でも日時が違えば別の計測として扱う |
| shotNo | ショット番号 | 任意 | 座標から番号を付ける（上の行から左→右） |
| Direction | Scan 方向（1 または 2） | 任意 | 「Scan 方向（Direction）が無い行に付ける値」の規則で付ける。規則が「付けない」なら Scan 方向を質的変数・制約に使わない |
| Xmm, Ymm | ショット中心の座標 [mm] | 必須 | |
| Radius | ショット中心の半径 [mm] | 任意 | あれば Xmm・Ymm からの計算値と合うか確かめる |
| markNo | ショット内のマーク番号 | 任意 | マーク座標の組ごとに番号を付ける |
| markXmm, markYmm | ショット中心から見たマーク座標 [mm] | 必須 | |
| measX, measY | マークの測定値 [nm] | 必須 | |
| StsX, StsY | ステータス（0 = 有効、−1 = 未測定） | 任意 | 測定値が空でなければ有効 |

`Operation`・`EqpId` は Overlay 計測ルールの標準の表には無い、このツールで追加した任意の項目です（工程名・装置 ID）。
評価の単位は Operation × EqpId × Wafer × DateTime。同じ Wafer が複数の単位にあるときは、表示名に違う項目（工程・装置・日時）を付けます（例：`W01 (OP1 / EXP02)`）。
工程・装置の一覧は「読み込み結果」と Excel の「説明」、値は「Waferごと」と推定値の Excel に出ます。

前処理（Overlay 計測ルールのとおり）

- 解析座標は x = Xmm + markXmm、y = Ymm + markYmm。半径 150 mm 以上の点は除く（画面で変えられる）。
- X には StsX = 0 の measX、Y には StsY = 0 の measY だけを使う。未測定を 0 として扱わない。
- Wafer・DateTime・Xmm・Ymm・markXmm・markYmm が同じ行は重複とみなし、測定値を X・Y それぞれ平均する。
- 除いた行・まとめた行の数は「読み込み結果」と書き出した Excel の「説明」シートに出る。

### 座標の単位

「1. データの読み込み」の右の **座標の単位（読み込むときに mm に変換する）** の表で、`Xmm`・`Ymm`・`markXmm`・`markYmm`・`Radius` ごとに入力の単位（mm／µm／nm／m）を選びます。初期値は mm。

- 表には、mm への倍率（m ×1000、µm ×0.001、nm ×0.000001）、ファイルの値（絶対値の最大）、変換後の値 [mm]、確認の結果が並びます。列名が `Xmm` でも、中身が µm なら µm を選びます。
- 確認の目安：Shot 中心（Xmm・Ymm・Radius）は 10〜300 mm、Mark（markXmm・markYmm）は 0.05〜50 mm。外れると「⚠」と、合いそうな単位が出ます。
- 「値の大きさから単位を推定」は、目安の外の列だけを、目安に入る単位に変えます。「まとめて選ぶ」は全列を同じ単位にします。
- 半径の照合・除外、重複・Shot の判定、マップ、推定には変換後の値を使います。`measX`・`measY` は nm のまま変換しません。
- 列の対応・座標の単位・有効半径・行の除外条件・Scan 方向の付与を変えたら、もう一度「この対応で読み込む」を押す。設定ファイルの読み込みでこれらが変わった場合も再読み込みが必要。入力ファイル自体は変更しない。

### Scan 方向が無いときの付与

`Direction` の列が無い、または空の行に、次の規則で Scan 方向 1・2 を付けられます（「1. データの読み込み」の「Scan 方向（Direction）が無い行に付ける値」）。初期値は「付けない」です。

| 規則 | 付け方 |
| --- | --- |
| shotNo の奇数 = 1・偶数 = 2 | 露光の順に Scan 方向が交互に変わり、shotNo が露光順の場合。shotNo の列が必要 |
| 市松模様 | Shot 行と Shot 列の番号の和の奇偶（上の行・左の列の Shot = 1） |
| Shot 行ごとに交互 | Shot 行の奇偶（上から1行目 = 1） |
| Shot 列ごとに交互 | Shot 列の奇偶（左から1列目 = 1） |

- Shot 行・列は、Wafer・測定日時ごとに入力の Shot 中心座標（半径・入力行の除外前、0.001 mm 刻み）から数えます。「付ける 1 と 2 を入れ替える」で反対にできます。
- `Direction` に値がある行はそのまま使います。付けた行の数と規則は「読み込み結果」と Excel の「説明」に出ます。付けた結果は「Shot レイアウト」（S1・S2）で確かめられます。
- 付けた Scan 方向は、ファイルの列と同じく質的変数・I 最適の制約に使います。設定 JSON の `data.directionRule`（`none`・`shotNoParity`・`checkerboard`・`rowParity`・`columnParity`）と `data.invertDirection` に保存されます。

### Wafer マップと Shot レイアウト

「この対応で読み込む」の後、「1. データの読み込み」の中のタブで読み込んだデータを確かめます。

- **Wafer マップ（計測値）**：計測値のベクトル（矢印）の隣に、X 成分・Y 成分のヒートマップ（色）を並べます。色の範囲は X・Y 共通。「色の点の大きさ」で点の大きさ（面積）を変えられます（「5. Wafer ごとのマップ」も同じ）。
- **Shot の枠**：Shot の大きさは、同じ行・列で隣り合う Shot 中心の間隔のうち最も小さい値から推定します（隣の Shot が無い向きは Mark の広がりの 1.2 倍）。Wafer マップでは灰色の枠で描き、「Shot の枠を表示」で消せます。
- **Shot レイアウト**：左は Shot の配置（枠・shotNo、Scan 方向があれば S1・S2 と色）と計測した Mark の位置、右は Shot 内の Mark の位置（Shot 中心からの座標）と markNo、その位置で計測した Shot の数です。

### 測定値・ステータスによる行の除外

「1. データの読み込み」で、次の2項目をそれぞれ選べます。初期値はどちらもオフです。

- **測定値 X・Y が両方 0 の行を除外**：入力の `measX = 0` かつ `measY = 0` の行を除外します。片方だけが0の行は残します。
- **StsX または StsY が −1 の行を除外**：どちらか一方でも−1なら、もう一方の測定値が有効でも行全体を除外します。オフの場合は従来どおり、無効な軸だけを解析から外します。Sts列がない・対応づけられていない場合は、その列による判定は行わず、読み込み結果に通知します。

判定は重複行の測定値を平均する前に行います。非ゼロの値を平均した結果が0になった点は除外しません。除外件数は、座標・有効半径による除外後の行について、選択中の条件ごとの件数と、重なりを除いた合計を表示します。Shot 行の奇偶は除外前の入力座標で決まり、除外によって番号を振り直しません。全行が除外される場合は、除外条件の見直しを案内します。

選択内容は設定JSONと結果Excelの「設定」に保存されます（`data.excludeZeroMeasurements`、`data.excludeUnmeasuredRecords`）。古い設定ファイルでは両方オフになります。

## 評価の考え方

- **学習 Shot 数**：開始・終了・刻み（スイープ幅）で指定する（例：10・40・5 → 10, 15, …, 40）。終了が刻みに乗らなければその手前まで。並びは欄の下に出る（上限 100 通り）。以前の設定 JSON（Shot 数の並びだけ）は、最小・最大・間隔の最大公約数から開始・終了・刻みを決める（等間隔でなければ間の Shot 数が加わる）。
- **学習と評価**：学習 Shot の計測値で推定し、学習しなかった Shot の **計測値** と比べる
  （実データには真の値が無いため。計測ノイズを含むので、模擬データの評価より誤差は少し大きく出る）。
- **学習 Shot の選び方**
  - 制約付き I 最適（前回の評価と同じ）：XY 5次多項式の平均予測分散が小さくなる Shot の組を交換法で探す。
    同心円（Wafer 半径比 0.45・0.7）・4象限・Scan 方向ごとの Shot 数を、全体の割合 ± 1 にそろえる。
  - 制約つきランダム：同じ制約を満たす組をランダムに選び、指定回数くり返す（乱数の種を固定すれば同じ組になる）。
  - 手動で指定：shotNo を並べた行を1パターンとして、何パターンでも比べられる。
  - 候補 Shot と計測できた Mark が同じ Wafer では、同じ学習 Shot を使う（同じ条件で比べるため）。
- **指標**：R²・自由度調整済み R²・RMSE・MAE（X・Y・X と Y の合計）。外周（半径比 0.8 以上）と内側の RMSE も出す。
- **集計**：Wafer ごとの値（ランダムのくり返しは平均）を、Wafer 間で 平均・中央値・ワースト値・95%値 にする。
  ワースト値は最も悪い Wafer の値（RMSE・MAE・処理時間は最大、R²・調整済み R² は最小）、95%値は 95% の Wafer がそれより良い値（RMSE・MAE・処理時間は 95 パーセント点、R² は 5 パーセント点。Excel の PERCENTILE.INC と同じ補間）。
  基準の手法との比較は、同じ Wafer・同じ学習パターンどうしの差の平均・95% 区間・基準より良かった Wafer の割合。
- **I 基準・D 基準**：学習 Shot の組ごとに、XY 多項式の基準モデル（I 最適の基準と同じ次数、候補の全 Mark で正規直交化）の情報行列 M から、I 基準 tr(M⁻¹)（平均予測分散に比例）と D 基準 det(M)^(−1/p)（p は項数）を求める。選び方（I 最適・ランダム・手動）によらず計算し、小さいほど良い計画。全候補を使うと I 基準 = p、D 基準 = 1。学習点が項数より少ないときは求めない。「4. 結果一覧」の「グラフ」で横軸を「I 基準と D 基準」にすると、2つの図を並べて、学習パターンの列ごとの推定誤差（上で選んだ指標・集計）を基準の値（Wafer の平均、対数目盛）に対して描く。「Wafer ごとの点も描く」で各 Wafer の点も重ねる。

比べられる手法

| 系統 | 選べるもの |
| --- | --- |
| GPR | fitrgp と同じ10カーネル、または ν を指定する Matérn（matern・ardmatern）× 説明変数（X,Y／X,Y,半径／X,Y,半径,T）× 質的変数（Scan 方向・Mark 番号）の8通りの扱い（使わない・同時推定・Backfitting・同時推定＋交互作用・加法カーネル・加法カーネル＋交互作用・混合・混合＋交互作用） |
| TPS | 平滑化つき薄板スプライン（λ は GCV）× 質的変数なし／Backfitting |
| RBF | ガウス型の動径基底関数＋1次多項式。広がりと平滑化は GCV で選択 |
| Kriging | 通常 Kriging・Universal Kriging × バリオグラム（linear・gaussian・power・exponential・spherical）× 質的変数なし／Backfitting |
| GAM | 形状関数を項（X・Y、半径、方位角）ごとに P-spline かガウス過程回帰から選ぶ（λ は REML）＋ Scan 方向・Mark 番号 |
| XY 多項式・RT モデル | 次数を指定 |

前処理として「XY 1次（並進・倍率・回転・直交度）を学習点で除いてから推定する」も選べます（実データで1次成分が大きいとき用。初期設定は使わない）。

### 処理時間の記録

1 枚あたりの推定時間を手法選びの判断に使うときは、「2. 評価の設定」の **条件ごとの処理時間を記録する** をオンにします（初期値はオフ）。

- 記録するのは、1 枚の X・Y の推定（当てはめと評価点の予測）にかかった秒数。学習パターン（I 最適の計画など）を作る時間は含めず、Excel の「学習Shot」に別に出す（同じ配置の Wafer で使い回した場合は 0）。
- 各手法を最初に使う前に、予備の推定を1回して結果を捨てる（ファイルの読み込みなど初回だけの時間を除くため）。そのぶん全体の時間は少し延びる。
- 「4. 結果一覧」の指標に「処理時間 [秒/枚]」が加わり、手法 × 学習パターンの表・グラフ・基準との比較（時間の差の割合）で見られる。Excel には「処理時間」シート（平均・中央値・95%値・最大・合計・回数）を足す。
- 時間は PC の性能や同時に動いているソフトで変わる。手法どうしは同じ PC・同じ実行の中で比べる。

### 推定値と誤差の分布

「4. 結果一覧」の **推定値と誤差の分布** で、手法・学習パターンの列・Wafer（すべて、または1枚）を選んで「分析する」を押すと、評価点の残差（計測値 − 推定値）を調べます（選んだ Wafer の評価点をまとめて扱い、ランダムのくり返しも含む）。

- **ヒストグラム**：X・Y の残差の分布に、同じ平均・標準偏差の正規分布の曲線を重ねる。
- **正規性検定**：点数・平均・標準偏差・歪度・尖度（過剰）と、Shapiro–Wilk（Royston の近似。3〜5000 点のときだけ）、Anderson–Darling（平均・分散を推定する場合の補正と p 値の近似）、Jarque–Bera の統計量と p 値。判定は Shapiro–Wilk の p 値（5000 点を超えるときは Anderson–Darling）が 0.05 未満なら「正規分布から外れている」。点数が多いと小さなずれでも p 値が小さくなるので、ヒストグラムと合わせて見る。
- **質的変数の ANOVA**：Scan 方向・Mark 番号・Shot 行の奇偶・工程（Operation）・装置（EqpId）ごとに、水準ごとの平均残差と F 検定。「一元配置」はその変数だけで分けた検定（η² は水準の違いで説明できる割合）、「ほかの変数で調整」は使える質的変数をすべて入れた主効果モデル（交互作用なし、Type II）からその変数を外したときの検定。同じ分け方になる変数（例：Scan 方向が Shot 行の奇偶と同じ）は区別できず、調整した検定は出さない。水準が1つしかない変数は検定しない。
- 検定は MATLAB 本体の関数（erfc・erfcinv・betainc）だけで計算する（Statistics and Machine Learning Toolbox は不要）。SciPy の shapiro・anderson・jarque_bera・f_oneway と照合済み（[tests/TestStatistics.m](tests/TestStatistics.m)）。

### 推定値の Excel

### Matérn の ν・spherical バリオグラム・GAM の形状関数

**GPR の Matérn カーネルの ν（次数）**

- 「カーネル」で **matern（ν を指定）**・**ardmatern（ν を指定）** を選び、「Matérn の ν」に値を空白区切りで入れる（例：`0.75 1 2 3.5`）。値ごとに別の手法として比べる（id は `GPR_matern_nu1.2_XYR_basis` のように ν を含む）。初期値は 2。
- 式は σf² · 2^(1−ν)/Γ(ν) · (√(2ν) r)^ν · K_ν(√(2ν) r)（r は長さスケールで割った距離、K_ν は第2種変形ベッセル関数）。ν が大きいほど滑らかで、ν = 0.5・1.5・2.5 で exponential・matern32・matern52 と同じ式になる（テストで 1e−12 以内の一致を確認）。使える範囲は 0 < ν ≤ 50。
- 超パラメータ（長さスケール・σf・σn など）は他のカーネルと同じく対数周辺尤度の最大化で推定する。ν は推定せず、入れた値に固定する。勾配は解析的に求め、数値微分との一致をテストで確認。MATLAB 本体の `besselk`・`gammaln` を使う（Toolbox 不要）。

**Kriging の spherical（球形）バリオグラム**

- 「バリオグラム」の **spherical** を選ぶ。γ(d) = psill·(3d/(2·range) − d³/(2·range³)) + nugget（d ≤ range）、psill + nugget（d > range）。PyKrige の spherical と同じ式・初期値・範囲・soft_l1 損失で当てはめる。
- 球形モデルは説明変数が3次元まで（X,Y・X,Y,半径）なら正定値が保証される。X,Y,半径,T（5列）では保証されないので、結果を他のバリオグラムと比べて使う。

**GAM の形状関数（スプライン・ガウス過程回帰）**

- 「GAM」の下の **形状関数** で、X・Y（2次元の項）、半径、方位角 θ の項ごとに **スプライン**（従来の P-spline）か **ガウス過程回帰** を選ぶ。半径の項は説明変数が X,Y,半径 以上、方位角の項は X,Y,半径,T のときだけ使う。初期値はすべてスプライン（従来と同じ結果）。
- ガウス過程回帰の項は Matérn 5/2 カーネルを節点で近似した低ランクのガウス過程：s(z) = 線形部分 + Σ b_k k(z, κ_k)、罰則 bᵀK(κ, κ)b。線形部分（X・Y の項は x・y、半径の項は r）は罰則なし（スプラインの2階差分の罰則と同じく、1次の変化は罰しない）。節点は X・Y が [−1, 1]² の 7 × 7 格子のうち Wafer の内側、半径は [0, 1] の 10 点、方位角は円周上の 10 点（距離は弦の長さ）。
- 罰則の強さ λ は、スプラインと同じく REML で項ごとに選ぶ。長さスケールは候補（0.15・0.3・0.6。Wafer 半径で割った単位）から、項ごとに順に REML の基準が最も小さいものを選ぶ（候補の数だけ当てはめ直すので、スプラインより時間がかかる）。選んだ長さスケールは Excel の「Waferごと」の超パラメータに `gpLength_<項>_<軸>` として残る。
- id は、ガウス過程回帰にした項を `_gp-` の後に付ける（例：`GAM_XYR_gp-xy-r`）。
- 詳細設定は JSON の `methods.gpr.maternNu`、`methods.gam.shapes`（`xy`・`r`・`theta` に `spline` か `gp`）、`methods.options.gamGpLengthScales`・`gamGpKnots`・`gamGpGridKnots`。古い設定 JSON では ν は 2、形状関数はすべてスプラインになる。

### RBF と TPS・Kriging の Backfitting

「2. 評価の設定」で **RBF（ガウス型・平滑化つき）** を選ぶと、RBF を手法比較に追加できます。説明変数は既存手法と同じ XY／XYR／XYRT です。RBF 自体には質的変数を追加しません。

TPS・Kriging（通常）・Universal Kriging の右側では、それぞれ **質的変数なし／Backfitting／なし・Backfitting を比較** を選べます。両方を選ぶと、同じ学習 Shot でそれぞれの結果が出ます。

- Backfitting は Scan 方向・Mark 番号と、チェックした場合は Shot 行奇偶を固定効果として扱う。質的変数の効果を除いた残差から空間成分を推定し、質的変数の効果を更新する。
- TPS は平滑化を、Kriging はバリオグラムを残差から選び直す。学習点で平滑化を固定した内側の交互反復は収束値を直接計算し、外側を最大20回、変化が 0.001 nm 未満になるまで繰り返す。評価点の計測値は当てはめにも設定選択にも使わない。
- 収束しなかった場合は「3. 実行」の記録と Excel の「説明」に通知し、最終反復の結果を残す。「Waferごと」の「最適化の収束」は false になる。有効自由度には質的変数と空間成分の両方を含める（最終パラメータ固定時の値）。
- RBF の基底は `exp(-r² / (2ℓ²))`。Wafer 半径で正規化した説明変数の距離で、ℓ の初期候補は 0.05・0.1・0.2・0.4・0.8・1.6。平滑化と合わせて学習データの GCV（一般化交差検証）が最小の候補を使う。選択した値は Excel の「超パラメータ」に残る。
- 詳細設定は JSON の `methods.options.rbfLengthScales`、`rbfLog10Lambda`（最小・最大・候補数）、`backfitMaxIterations`、`backfitToleranceNm` で指定する。RBF の候補や Backfitting の反復が増えると計算時間も増える。
- 従来の設定と結果を再現できるよう、「推奨の組み合わせ」は従来の9手法を維持する。RBF と追加の Backfitting は個別に選ぶか「すべて選ぶ」で追加する。古い設定JSONでは RBF はオフ、TPS・Kriging の質的変数は「なし」になる。

### Shot 配列の行の奇数・偶数を使う

「2. 評価の設定」の「比べる手法」にある **Shot 行の奇数・偶数を質的変数に追加** を選びます。GPR・GAM と、Backfitting を選んだ TPS・Kriging に適用します。初期値はオフです。

- 各 Wafer・測定日時について、Shot 中心の `Ymm` を大きい順（上から）に並べ、1行目を奇数行、2行目を偶数行として扱う。同じ Y 座標の Shot とその Mark は同じ分類になる。座標は変換後の mm を小数点以下3桁に丸めて判定する。
- Excel の行番号や `shotNo` の奇偶ではない。半径で点を除く前の入力座標を使うため、有効半径を変えても分類は変わらない。ただし、入力に一切含まれない Shot 行は数えられない。欠落行を含む装置側の行番号を再現する機能ではない。
- Scan 方向・Mark 番号に追加される。GPR の「使わない」ではこの分類も使わない。同時推定・Backfitting・GAMでは固定効果、加法カーネルでは変量効果、混合ではScan方向と行奇偶が固定効果、Mark番号が変量効果になる。
- 「交互作用あり」は、Scan×Mark、Scan×行奇偶、Mark×行奇偶の各ペアを含む。学習点の水準が1種類しかない変数は効果を推定しない。Scan方向と行奇偶が一致する場合など、固定効果の重複する列は除く。
- 入力単位と行奇偶の使用設定は設定JSONと結果Excelに保存される。既存の設定JSONにこの項目が無ければ、座標はmm、行奇偶はオフになる。

## 計算時間の目安

M1 Mac（MATLAB R2022b、Intel 版を Rosetta で実行）で、約150 Shot・600 Mark の Wafer の場合：

- 1回の推定（X・Y）：GPR・GAM 約0.08 秒、Kriging 0.03 秒、TPS 0.02 秒、XY 多項式・RT 0.01 秒
- I 最適の計画：Shot 数1つあたり約5〜10 秒（同じ配置の Wafer では1回だけ）
- 推奨の組み合わせ（9手法）× 7つの Shot 数 × 25枚：約2〜3分
- 「すべて選ぶ」は追加機能込みで363手法（ν を指定する Matérn は ν = 2 の1つ、spherical を含む）。Backfitting の反復を含むため、所要時間は従来の273手法より長くなる（画面の目安では追加 Backfitting に反復上限を掛けている）。
- ν を指定する Matérn はベッセル関数を使うぶん、目安では matern52 の2倍とみている。GAM のガウス過程回帰の項は、長さスケールの候補を試す回数を掛けた保守的な目安。
