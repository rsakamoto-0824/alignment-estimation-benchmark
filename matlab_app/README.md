# 面内推定評価ツール（MATLAB アプリ）

アライメント計測値の面内推定の手法比較を、**実データ（Excel）** で確かめるための画面つきアプリです。
Excel の計測データを読み込み、画面で比べ方を決めて実行し、結果の表・グラフ・Wafer ごとの図を画面で確認します。
推定の計算は、模擬データで評価した Python 版（リポジトリの `src/`）を MATLAB に移したもので、同じ計算結果になることを照合しています（下の「動作確認」）。

- **Windows での使い方・exe の作り方の手順書（HTML）**：[docs/windows_guide/windows_guide.html](docs/windows_guide/windows_guide.html)（ブラウザで開く。画像・CSS が同じフォルダにあるので、フォルダごと扱う）
- **管理者向けの資料（アプリの構成と保守、HTML）**：[docs/admin_guide/admin_guide.html](docs/admin_guide/admin_guide.html)（フォルダの中身・処理の流れ・設定と Excel の列・保守で想定される作業と直す場所・テストと exe の作り直し・困ったとき）
- **管理者向けの画面編集手順書（HTML、13章・画像8枚）**：[docs/admin_guide/ui_editing/ui-editing-guide.html](docs/admin_guide/ui_editing/ui-editing-guide.html)（文字・配置・説明行・設定・コールバックの編集、再起動確認、Windows版の再作成。画像を内包した単独HTML）

## 使い方（MATLAB の中で）

1. MATLAB で `matlab_app` フォルダを開く（現在のフォルダにする）。
2. コマンドウィンドウで次を入力する。

   ```matlab
   runAlignmentEstimationApp
   ```

3. 画面のタブを左から順に進める。

| タブ | すること |
| --- | --- |
| 1. データの読み込み | 「ファイルを選ぶ…」で Excel（または CSV）を選ぶ。座標の定義（Shot 中心＋Shot 内の位置／絶対座標だけ）と推定する値（X・Y 成分／膜厚・線幅などの1変数）を選び、列の対応・座標の単位・行の除外条件・Scan 方向の付与を確かめて「この対応で読み込む」。中のタブ「Wafer マップ（計測値）」でベクトルと X・Y のヒートマップ（Shot の枠を Scan 方向で色分け・同心円の区切りも描ける）、「Shot レイアウト」で Shot の枠・shotNo・Mark の位置と番号、「Shot 重ね合わせ」で選んだ Wafer の全 Shot を重ねたベクトル場と共分散楕円を確かめる。「質的変数の交互作用」で、質的変数の効果と2つずつの交互作用（説明変数・カーネルを選ぶ目安つき）を確かめる |
| 2. 評価の設定 | 学習に使う Shot の選び方（I 最適・D 最適・ランダム・手動・人の選択（Excel から読み込める）・ファイルの優先順・Mark 単位の I 最適・D 最適。2つ以上選ぶと選び方どうしを比べる）、学習 Shot 数（Shot 数または計測率の開始・終了・刻み）、必ず計測する Shot（shotNo の指定・最外周）、制約（同心円の区切りは Shot 中心の半径 [mm]）、比べる手法を選ぶ（初期設定は「推奨の組み合わせ」）。外周とみなす半径も mm で入れる。必要なら学習データの異常値の除外（nσ または MAD で判定）・処理時間の記録をオンにする。Overlay 補正の評価の成分（Wafer 成分・Shot 共通成分・Shot ごとの成分。どれも式を入力できる）を選ぶ。交換法の初期配置の数の横に、学習パターンを作る時間の目安が出る。表示：Scan 方向 1・2 の向き（▲ 上・▼ 下）と色 |
| 3. 実行 | 「評価を始める」。進み具合と残り時間が出る。「一時中断」で途中までの結果を残して止め、「続きから再開」で残りを計算できる。評価の後に手法・学習 Shot 数を増やしたときは「条件を追加して評価」で、増えた組み合わせだけを計算して今の結果に足せる。右の「計測マップ」で、評価の前に学習に使う Shot を Wafer 上で確かめ（Wafer・学習パターンを複数選ぶと並べて描く。Scan 方向の色・同心円の区切りも）、画像・Excel に書き出せる |
| 4. 結果一覧 | 手法 × 学習 Shot 数 の表（各列の最良に ★。集計は平均・中央値・ワースト値・95%値。指標には平均値・中央値に対する改善量・改善率も）、グラフ（横軸は学習 Shot 数、または I 基準・D 基準。エラーバーも描ける）、基準の手法との比較、推定値と誤差の分布（ヒストグラム・正規性検定・ANOVA。手法を複数選んで並べられる）、残差の箱ひげ図（ANOVA の質的変数の水準ごと。手法を色分け）、推定値と実測値の散布図（色分けできる。外周・内側、象限、Slot の偶奇も）、残差と説明変数の散布図（座標・半径・方位角・Shot 内の位置と残差の相関）、分布の比較（全面・学習・予測対象・推定値のヒストグラム・代表統計値・JS ダイバージェンス）、処理時間の内訳（学習パターンの作成・異常値の判定・学習・推論などの割合）、計測配置の比較（選び方ごとの、計測する Mark の数・学習 Shot 数・D 効率・I 効率に対する指標と I 基準・D 基準。Wafer のばらつきのエラーバーも描ける）。上の「評価点の絞り込み」で、半径・Shot の条件に合う評価点だけで指標を計算し直せる。評価結果と推定値をそれぞれ Excel に書き出せる。「結果を読み込む…」で、書き出した評価結果の Excel を読み込んで表・グラフを描き直せる |
| 5. Wafer ごとのマップ | Wafer・学習パターン・手法を選び、計測値・推定値・残差を矢印または色で表示（Shot の枠、色の点の大きさを変えられる。Shot の枠を Scan 方向で色分け・同心円の区切りも描ける）。「図の内容」を「Overlay 補正」にすると、実測値で補正した残差・推定値で補正した残差・推定による変化を表示。右の一覧に条件（Wafer・平均 × 学習パターン × 手法）を足すと、同じ値の種類・同じ色の範囲で並べて比べられる。評価点の絞り込み（結果一覧と共通）も使える。残差の図の題名と下の説明に、RMSE に加えてワースト値と 95%値を出す |
| 6. 未知の座標の推定 | 計測していない座標（新しい Mark の位置・Wafer 上の任意の点）の推定値を求める。点は Excel・CSV から読み込むか、画面の表で入力・作成（全 Shot の同じ位置・格子）する。Wafer・学習データ（計測値のある全 Mark、または評価の学習パターン。どちらも複数選んで一括で推定できる）・手法を選んで「推定する」。学習点の範囲の外（外挿）の点・学習に無い Mark 番号は、画面の上にメッセージを出し、表・図でも示す。300 mm Wafer の外の点は推定の対象外（推定値 0、図から除く）。推定した後に「重ね合わせ補正値を計算する」で補正値を求められる。推定値と補正値は Excel に書き出せる（下の「未知の座標の推定」） |
| 7. ヘルプ | 主な専門用語、比べる手法、すべてのカーネル（GPR・GAM のガウス過程・Kriging のバリオグラム・TPS・RBF）の式、Fringe Zernike の項、Overlay 補正の式（成分・メーカー別の式・評価の定義・式の書き方）。メニュー「表示」→「ヘルプを開く」でも開く |

## スタンドアローン版の作り方（Windows）

MATLAB Compiler の入った Windows PC で行います（Mac では Windows 用の .exe は作れません）。

1. `matlab_app` フォルダごと Windows PC にコピーする。
2. MATLAB で `matlab_app` フォルダを開き、次を入力する（数分かかる）。

   ```matlab
   addpath build
   buildStandaloneApp                       % .exe だけ作る
   buildStandaloneApp(makeInstaller=true)   % インストーラーも作る（MATLAB Runtime をネットから入れる形）
   buildStandaloneApp(makeInstaller=true, runtimeDelivery="installer")  % Runtime 入りのインストーラー（ネットに出られない PC 用）
   ```

3. `build/output/win64/` に `AlignmentEstimationApp.exe` ができる。使う PC に同じ版の MATLAB Runtime を入れてから起動する
   （インストーラー版なら Runtime も一緒に入る）。

スタンドアローン版は画面だけのアプリとして作ります（コマンド画面は出ません）。設定・結果の保存先は、画面のダイアログで選んだ場所です。

## 読み込むデータの形

1行目が項目名、2行目からデータの表です（Excel のシートを選べます）。項目名は Overlay 計測ルールの
アライメント計測テーブルの標準に合わせます。名前が違う場合は、画面の「列の対応」で選び直せます。

| 項目名 | 意味 | 必須 | 無いとき |
| --- | --- | :---: | --- |
| Operation | 工程名 | 任意 | 空。同じ Wafer でも工程が違えば別の計測として扱う |
| EqpId | 装置 ID | 任意 | 空。同じ Wafer でも装置が違えば別の計測として扱う |
| LotID | ロット ID | 任意 | 空。同じ Wafer ID でもロットが違えば別の計測として扱う |
| Wafer | ウェハ ID | 任意 | 全行を1枚とみなす |
| DateTime | 測定日時 | 任意 | 空。同じ Wafer でも日時が違えば別の計測として扱う |
| shotNo | ショット番号 | 任意 | 座標から番号を付ける（上の行から左→右） |
| Direction | Scan 方向（1 または 2） | 任意 | 「Scan 方向（Direction）が無い行に付ける値」の規則で付ける。規則が「付けない」なら Scan 方向を質的変数・制約に使わない |
| Xmm, Ymm | ショット中心の座標 [mm]（座標の定義が絶対座標だけなら、点の座標） | 必須 | |
| Radius | ショット中心の半径 [mm] | 任意 | あれば Xmm・Ymm からの計算値と合うか確かめる |
| markNo | ショット内のマーク番号 | 任意 | マーク座標の組ごとに番号を付ける |
| markXmm, markYmm | ショット中心から見たマーク座標 [mm] | 必須（絶対座標だけなら任意） | 絶対座標だけのとき：shotNo から Shot 中心を決めるか、点を1つずつ Shot にする（下の「座標の定義」） |
| measX, measY | マークの測定値 [nm] | 必須（1変数なら使わない） | 1変数のときは「推定する値」で選んだ列を使う（下の「推定する値」） |
| StsX, StsY | ステータス（0 = 有効、−1 = 未測定） | 任意 | 測定値が空でなければ有効 |

`Operation`・`EqpId`・`LotID` は Overlay 計測ルールの標準の表には無い、このツールで追加した任意の項目です（工程名・装置 ID・ロット ID）。
評価の単位は Operation × EqpId × LotID × Wafer × DateTime。同じ Wafer ID が複数の単位にあるときは、表示名に違う項目（ロット・工程・装置・日時）を付けます（例：`W01 (LOT2)`、`W01 (OP1 / EXP02)`）。
工程・装置・ロットの一覧は「読み込み結果」と Excel の「説明」、値は「Waferごと」と推定値の Excel に出ます。残差の ANOVA ではロットも質的変数として調べます。

標準の項目に対応づけなかったファイルの列（例：Chuck、Reticle）は、読み込み時に Mark ごとの値（文字列）として残し、「2. 評価の設定」で質的変数に選べます（下の「質的変数を選ぶ」）。

前処理（Overlay 計測ルールのとおり）

- 解析座標は x = Xmm + markXmm、y = Ymm + markYmm。半径 150 mm 以上の点は除く（画面で変えられる）。
- X には StsX = 0 の measX、Y には StsY = 0 の measY だけを使う。未測定を 0 として扱わない。
- Wafer・DateTime・Xmm・Ymm・markXmm・markYmm が同じ行は重複とみなし、測定値を X・Y それぞれ平均する。
- 除いた行・まとめた行の数は「読み込み結果」と書き出した Excel の「説明」シートに出る。

### 座標の定義（絶対座標だけのデータ）

「1. データの読み込み」の **座標の定義** で、点の座標の書き方を選びます（設定 JSON の `data.coordinateMode`）。

| 座標の定義 | Xmm・Ymm の列 | Shot 中心と Shot 内の位置 |
| --- | --- | --- |
| Shot 中心＋Shot 内の位置（初期値、`shotMark`） | Shot 中心の座標 | markXmm・markYmm（必須）。点の座標 x = Xmm + markXmm |
| Wafer 上の絶対座標だけ（`absolute`） | 点（Mark・測定点）の Wafer 上の座標 x = Xmm | markXmm・markYmm があれば Shot 中心 = x − markXmm。無くて shotNo があれば、同じ Wafer・shotNo の点の平均を Shot 中心にする（重複の行は1点として数える）。どちらも無ければ **点を1つずつ Shot として扱う** |

- 点を1つずつ Shot として扱うとき：「学習 Shot」は学習に使う点、Mark 番号はすべて 1（Mark 番号は質的変数に使われない）、Scan 方向は付けない（Direction の列があればそれを使う）。Shot の枠は、最も近い点までの距離の中央値 × 0.6 の正方形にする（隣の点の枠と重ならない大きさ。図と、未知の座標の点がどの点の近くかを見るときだけに使う）。
- 列の名前が `X`・`Y` などでも、「列の対応」で Xmm・Ymm の行に選べば使える（座標の単位も選べる）。

### 推定する値（X・Y 成分、または膜厚・線幅などの1変数）

「1. データの読み込み」の **推定する値** で、X・Y 成分（measX・measY、初期値）か、ファイルの1つの列（膜厚・線幅など）を選びます。1つの列を選ぶと **1変数** として推定します（設定 JSON の `data.valueColumn` に列の名前、`data.valueUnit` に単位。単位は画面と Excel の表示だけに使い、換算はしない）。

- 1変数の値は中では X 成分として扱い、Y 成分は使いません。measX・measY・StsX・StsY の列は使わず（任意になる）、値が空・数でない点を無効にします。その列は質的変数の候補にしません。
- 指標：X・Y 合計の指標（RMSE_XY など）は、Y が無いのでその1変数の指標と同じ値です。画面の指標は「RMSE [nm]（Thickness_nm）」のように値の名前と単位で出し、X・Y 別の指標は出しません。Excel の列名は今までどおり（X と X・Y 合計の列がその値、Y の列は空欄）で、「説明」シートに「推定した値」を書きます。
- 使えないもの：X・Y の2成分が要る **RT モデル**（比べる手法から自動で外し、記録に出す）、**Overlay 補正の評価**（「2. 評価の設定」で選べなくなる）、矢印（ベクトル）の図・共分散楕円・Shot 重ね合わせ。図は値の色で描き、計測値・推定値は値の最小〜最大、残差は 0 を中心にした色の範囲です。
- 未知の座標の推定・誤差の分布・散布図・分布の比較・計測配置の比較は1変数でも使えます（図・表は1枚・1列）。

動作確認用の1変数・絶対座標の見本：[sample_data/sample_thickness.csv](sample_data/sample_thickness.csv)（膜厚の模擬データ、Wafer 5 枚 × 109 点、列 Wafer・Xmm・Ymm・Thickness_nm・Chamber。作り方は [sample_data/make_sample_thickness.m](sample_data/make_sample_thickness.m)）。座標の定義を「Wafer 上の絶対座標だけ」、推定する値を「1変数：Thickness_nm」にして読み込みます。

### 座標の単位

「1. データの読み込み」の右の **座標の単位（読み込むときに mm に変換する）** の表で、`Xmm`・`Ymm`・`markXmm`・`markYmm`・`Radius` ごとに入力の単位（mm／µm／nm／m）を選びます。初期値は mm。

- 表には、mm への倍率（m ×1000、µm ×0.001、nm ×0.000001）、ファイルの値（絶対値の最大）、変換後の値 [mm]、確認の結果が並びます。列名が `Xmm` でも、中身が µm なら µm を選びます。
- 確認の目安：Shot 中心（Xmm・Ymm・Radius）は 10〜300 mm、Mark（markXmm・markYmm）は 0.05〜50 mm。外れると「⚠」と、合いそうな単位が出ます。
- 「値の大きさから単位を推定」は、目安の外の列だけを、目安に入る単位に変えます。「まとめて選ぶ」は全列を同じ単位にします。
- 半径の照合・除外、重複・Shot の判定、マップ、推定には変換後の値を使います。`measX`・`measY` は nm のまま変換しません。
- 列の対応・座標の単位・有効半径・行の除外条件・Scan 方向の付与を変えたら、もう一度「この対応で読み込む」を押す。設定ファイルの読み込みでこれらが変わった場合も再読み込みが必要。入力ファイル自体は変更しない。

### Scan 方向が無いときの付与

`Direction` の列が無い、または空の行に、次の規則で Scan 方向 1・2 を付けられます（「1. データの読み込み」の「Scan 方向（Direction）が無い行に付ける値」）。初期値は「一筆書き」です（「付けない」も選べる）。

| 規則 | 付け方 |
| --- | --- |
| 一筆書き（初期値） | shotNo が最も小さい Shot を 1（+1 方向）として、その行を近い端から遠い端へ、次の行（始めの行から遠ざかる向き）は逆向きにたどる（行ごとに折り返す）道順で Shot を繋ぎ、道順に 1・2 を交互に付ける。shotNo の列が無ければ、いちばん上の行の左端から始める |
| shotNo の奇数 = 1・偶数 = 2 | 露光の順に Scan 方向が交互に変わり、shotNo が露光順の場合。shotNo の列が必要 |
| 市松模様 | Shot 行と Shot 列の番号の和の奇偶（上の行・左の列の Shot = 1） |
| Shot 行ごとに交互 | Shot 行の奇偶（上から1行目 = 1） |
| Shot 列ごとに交互 | Shot 列の奇偶（左から1列目 = 1） |

- Shot 行・列は、Wafer・測定日時ごとに入力の Shot 中心座標（半径・入力行の除外前、0.001 mm 刻み）から数えます。「付ける 1 と 2 を入れ替える」で反対にできます。
- `Direction` に値がある行はそのまま使います。付けた行の数と規則は「読み込み結果」と Excel の「説明」に出ます。付けた結果は「Shot レイアウト」（S1・S2）で確かめられます。
- 付けた Scan 方向は、ファイルの列と同じく質的変数・I 最適の制約に使います。設定 JSON の `data.directionRule`（`none`・`serpentine`・`shotNoParity`・`checkerboard`・`rowParity`・`columnParity`）と `data.invertDirection` に保存されます。以前の設定 JSON（規則が無い）は一筆書きになります。
- **画面での変更**：「Shot レイアウト」の左の図で Shot をクリックすると、その shotNo の Scan 方向を 1 ↔ 2 で入れ替えます（方向が無ければ 1）。すべての Wafer の同じ shotNo に当て、すぐに読み込み直します（評価の結果は消える）。規則やファイルの値より優先し、変えた Shot は図の上と「読み込み結果」に出ます。「Scan 方向の変更を元に戻す」で全部戻せます。設定 JSON の `data.directionOverrideShots`・`directionOverrideValues` に保存されます。

### Wafer マップと Shot レイアウト

「この対応で読み込む」の後、「1. データの読み込み」の中のタブで読み込んだデータを確かめます。

- **Wafer マップ（計測値）**：計測値のベクトル（矢印）の隣に、X 成分・Y 成分のヒートマップ（色）を並べます。色の範囲は X・Y 共通。「色の点」で点の大きさ（面積）と形（● か ■）を変えられます（「5. Wafer ごとのマップ」も同じ）。
- **矢印の色**：すべての Wafer マップ・Shot 重ね合わせで、矢印の色は長さ |v| [nm]（青 → 緑 → 橙 → 赤）。図の右の目盛りが長さ。共分散楕円と重ねる図では、矢印は単色にして、右の目盛りは楕円の |r| に使う（下の「Wafer の平均の図と共分散楕円」）。「5. Wafer ごとのマップ」では計測値と推定値（Overlay 補正では2つの補正残差）の色の範囲をそろえ、残差・推定による変化はそれぞれの最大までの色にします。
- **表示名**：Wafer の名前は Wafer ID。Operation・EqpId・LotID のどれかがデータの中で2種類以上あれば、その値を付けます（例：`SIM01 (EXP01)`）。同じ Wafer ID でも工程・装置・ロット・測定日時が違えば別の計測で、名前でも区別できます。
- **Shot の枠**：Shot の大きさは、同じ行・列で隣り合う Shot 中心の間隔のうち最も小さい値から推定します（隣の Shot が無い向きは Mark の広がりの 1.2 倍）。Wafer マップでは灰色の枠で描き、「Shot の枠を表示」で消せます。
- **Shot レイアウト**：左は Shot の配置（枠・shotNo、Scan 方向があれば S1・S2 と色）と計測した Mark の位置、右は Shot 内の Mark の位置（Shot 中心からの座標）と markNo、その位置で計測した Shot の数です。

### 測定値・ステータスによる行の除外

「1. データの読み込み」で、次の2項目をそれぞれ選べます。初期値はどちらもオフです。

- **測定値 X・Y が両方 0 の行を除外**：入力の `measX = 0` かつ `measY = 0` の行を除外します。片方だけが0の行は残します。
- **StsX または StsY が −1 の行を除外**：どちらか一方でも−1なら、もう一方の測定値が有効でも行全体を除外します。オフの場合は従来どおり、無効な軸だけを解析から外します。Sts列がない・対応づけられていない場合は、その列による判定は行わず、読み込み結果に通知します。

判定は重複行の測定値を平均する前に行います。非ゼロの値を平均した結果が0になった点は除外しません。除外件数は、座標・有効半径による除外後の行について、選択中の条件ごとの件数と、重なりを除いた合計を表示します。Shot 行の奇偶は除外前の入力座標で決まり、除外によって番号を振り直しません。全行が除外される場合は、除外条件の見直しを案内します。

選択内容は設定JSONと結果Excelの「設定」に保存されます（`data.excludeZeroMeasurements`、`data.excludeUnmeasuredRecords`）。古い設定ファイルでは両方オフになります。

## 評価の考え方

- **学習 Shot 数**：開始・終了・刻み（スイープ幅）で指定する（例：10・40・5 → 10, 15, …, 40）。終了が刻みに乗らなければその手前まで。並びは欄の下に出る（上限 100 通り）。以前の設定 JSON（Shot 数の並びだけ）は、最小・最大・間隔の最大公約数から開始・終了・刻みを決める（等間隔でなければ間の Shot 数が加わる）。
- **計測率でのスイープ**：「学習 Shot 数」の右で「計測率 [%] で決める」を選ぶと、計測率（候補 Shot ＝計測値のある Shot に対する学習 Shot の割合）の開始・終了・刻みで比べる（例：10・40・10 → 10, 20, 30, 40 %。小数も可。0 より大きく 100 より小さい）。Wafer ごとに round(計測率 / 100 × 候補 Shot 数)（1 以上）の Shot を学習に使う。学習パターンは「I最適 計測率 20%」、結果の列は「計測率 20%」、グラフの横軸は計測率 [%] になる。手動の指定では使わない。
- **学習と評価**：学習 Shot の計測値で推定し、学習しなかった Shot の **計測値** と比べる
  （実データには真の値が無いため。計測ノイズを含むので、模擬データの評価より誤差は少し大きく出る）。
- **学習 Shot の選び方**
  - 制約付き I 最適（前回の評価と同じ）：XY 5次多項式の平均予測分散が小さくなる Shot の組を交換法で探す。
    同心円（Shot 中心の半径 67.5 mm・105 mm で区切る）・4象限・Scan 方向ごとの Shot 数を、全体の割合 ± 1 にそろえる。
    同心円の区切りは「2. 評価の設定」で Shot 中心の半径 [mm] を空白で区切って入れる（半径 150 mm の Wafer が前提。
    0 より大きく 150 より小さい値。使わないなら空欄）。以前の設定 JSON・評価結果の Excel の「Wafer 半径に対する比」
    （0.45・0.7 など）は、読み込むときに 比 × 150 mm に直す。
  - 制約つきランダム：同じ制約を満たす組をランダムに選び、指定回数くり返す（乱数の種を固定すれば同じ組になる）。
  - 制約付き D 最適：I 最適と同じ基準モデル・制約で、情報行列の行列式 det(M) が大きくなる（D 基準 det(M)^(−1/p) が小さくなる）組を交換法で探す。D 最適は基準モデルの係数をまとめて精度よく決める計画、I 最適は Wafer 全面の予測の分散を小さくする計画。必ず計測する Shot も I 最適と同じように使う。
  - 手動・人の選択：「名前: shotNo shotNo …」の行（名前は省略可）を1パターンとして、何パターンでも比べられる。**人の選択を Excel から読み込む…** で、人が選んだ計測配置の表（1行目が見出し。shotNo の列と、パターンごとの列に 1 = 計測する・0 = しない）を読み込むと、見出しをパターンの名前にして1パターン1行で入る（「計測マップを Excel に書き出す…」で書き出した「計測マップ」シートに列を足してもよい。座標・行・列などの列と、全 Shot が 1 の列は読み飛ばす）。
  - Mark 単位の I 最適・D 最適：Shot ではなく **Mark** を選ぶ（D 最適は det(M) を大きくする組）。「1 Shot あたりの計測 Mark 数」（初期値 1。空白区切りで複数入れると比べる）× 候補 Shot 数 の Mark を、Mark ごとの基準モデルの行で交換法で選ぶ。学習 Shot 数の決め方で **計測率** を選ぶと、代わりに計測率（候補の全 Mark の数に対する割合）の開始・終了・刻みでスイープする（「Mark最適 計測率 20%」「MarkD最適 計測率 20%」）。**Shot ごとに n 点の Mark 計測を必須にする**（初期値オン、n = 1）では、各 Shot で n 点以上（Mark が n 点より少ない Shot はその全 Mark）を必ず計測し、計測する数が足りないときは増やしてメモに書く。オフにすると Shot を問わず選ぶ（計測しない Shot もある）。「Mark 番号ごとの計測割合を全計測とそろえる」（初期値オン）では、Mark 番号ごとの計測数を、全 Mark を計測したときの Mark 番号の割合（± 許容幅）にそろえる。評価は計測しなかった Mark（計測した Shot の残りの Mark も含む）で行う。学習パターンは「Mark最適 1 点/Shot」。計測マップでは計測する Mark を ●、しない Mark を ○ で描き、Excel に「計測マップ_Mark」シートを加える。設定 JSON では `sampling.markPerShot`・`sampling.constraints.markRatio`・`sampling.markRequirePerShot`・`sampling.markMinPerShot`。
  - 選び方は Ctrl・Shift で **複数** 選べる。2つ以上選ぶと学習パターンの名前の先頭に選び方が付き（「I最適 20 Shot」「D最適 20 Shot」「人A」「Mark最適 1 点/Shot」）、「4. 結果一覧」の **計測配置の比較** で比べられる（下）。設定 JSON の `sampling.method` は選び方の並び（`ioptimal`・`doptimal`・`random`・`manual`・`file`・`mark`・`markd`）。
  - 候補 Shot と計測できた Mark が同じ Wafer では、同じ学習 Shot を使う（同じ条件で比べるため）。
- **必ず計測する Shot（拡張 I 最適計画）**：I 最適・ランダムでは、「必ず計測する shotNo」に書いた Shot と、「最外周の Shot をすべて必ず計測する」をオンにしたときの最外周の Shot を先に学習に入れ、残りを I 最適（またはランダム）で選ぶ。交換法は必ず計測する Shot を外さず、残りの Shot だけを入れ替えて I 基準を小さくする。
  - 最外周の Shot：Shot の行・列（Shot 中心の座標から数えた格子の位置）で、上下左右のどこかに隣の Shot が無い Shot。半径の外などで Shot が無い所の内側の Shot も入る。
  - 必ず計測する Shot が学習 Shot 数以上なら、それだけを使う（記録に出す）。Wafer に無い・計測値の無い shotNo は飛ばして記録に出す。
  - 必ず計測する Shot が制約（同心円・4象限・Scan 方向の Shot 数）とぶつかるときは、残りの Shot で違反ができるだけ少なくなる組を使い、違反量を記録に出す。
  - 欄の下に、最初の Wafer で必ず計測する Shot の数（指定・最外周の内訳）が出る。設定 JSON では `sampling.requiredShots`・`requireOuterShots`。
- **計測マップ**：「3. 実行」の右の「計測マップ」で Wafer と学習パターンを選び「計測マップを作る」を押すと、必ず計測する Shot（橙・太枠）、選んで計測する Shot（青）、計測しない Shot（白、評価に使う）、計測値の無い Shot（灰）を Wafer 上に shotNo つきで描く（計測する Shot の番号は太字）。Wafer・学習パターンを Ctrl・Shift で複数選ぶと、Wafer × 学習パターンの図を最大 6 枚並べる（凡例は右に1つ。区分ごとの数は下の欄）。「Scan 方向を色で示す」をオンにすると Shot の内側に Scan 方向の色の枠と印（既定は緑 ▲ = 1、紫 ▼ = 2。下の「Scan 方向の向きと色」で変えられる）、「同心円の区切り（制約）を描く」で区切りの半径を橙の一点鎖線で描く（Scan 方向・同心円の制約で Shot 数がそろっているかを目で確かめる）。評価と同じ作り方なので、同じ設定なら評価でも同じ Shot を使う。下の欄に Shot 数・計測率・I 基準・D 基準・制約の違反量・計測する shotNo が出る。「図を画像で保存…」で PNG、「計測マップを Excel に書き出す…」で選んだ Wafer のすべての学習パターンを書き出す（「計測マップ」シート：Shot ごとの座標・行・列・Scan 方向・最外周・指定の有無と、学習パターンごとの 1 = 計測する／0 = しない。「学習パターン」シート：Shot 数・計測率・必ず計測した数・I 基準・D 基準・shotNo・メモ）。
- **学習データの異常値の除外**：「評価」の「学習データの異常値を除いて推定する」をオンにし、右の「n =」に値を入れると、Wafer・学習パターン（計測マップ）ごとに学習点の平均と σ（標本標準偏差）を X・Y 別に求め、|値 − 平均| が n × σ を超える軸が1つでもある Mark を、X・Y の両方の学習データから除いて推定する（n は任意の正の値、初期値 3。平均・σ は1回だけ求める）。判定は **nσ**（平均と標本標準偏差）か **MAD**（中央値と 1.4826 × 中央絶対偏差。正規分布なら σ と同じ大きさ）を選べる（設定 JSON の `evaluation.outlierMethod` = `sigma`・`mad`）。MAD は外れ値そのものにばらつきが引きずられにくいので、大きな外れ値が混じるときに使う。除いた Mark は評価にも使わない（学習 Shot の Mark なので）。除いた数は Excel の「Waferごと」の「学習から除いた異常値の数」、Wafer ごとのマップでは × 印と下の説明に出る。Overlay 補正の評価では、学習 Shot の補正量に実際の計測値を使う（除いた Mark も含む）。
- **指標**：R²・RMSE・MAE（X・Y・X と Y の合計）。外周（Mark の半径 120 mm 以上。「外周とみなす Mark の半径 [mm]」で変えられる）と内側の RMSE も出す（自由度調整済み決定係数は出さない）。
- **平均値・中央値に対する改善**：学習点の計測値の平均値（または中央値。X・Y 別）をそのまま全評価点の推定値にした場合の RMSE（X・Y 合計）と、それに対する手法の改善量 = その RMSE − 手法の RMSE [nm]、改善率 = 改善量 / その RMSE × 100 [%]（大きいほど良い。0 なら平均値と同じ、負なら平均値より悪い）。学習点は手法と同じ（学習データの異常値を除く設定なら除いた後）。「指標」で選べ、表・グラフ・ワースト値・95%値・基準との比較・Excel（集計_improveMeanPct_XY・集計_improveMedianPct_XY、Waferごと）に出る。
- **集計**：Wafer ごとの値（ランダムのくり返しは平均）を、Wafer 間で 平均・中央値・ワースト値・95%値 にする。
  ワースト値は最も悪い Wafer の値（RMSE・MAE・処理時間は最大、R²・改善量・改善率は最小）、95%値は 95% の Wafer がそれより良い値（RMSE・MAE・処理時間は 95 パーセント点、R² は 5 パーセント点。Excel の PERCENTILE.INC と同じ補間）。
  基準の手法との比較は、同じ Wafer・同じ学習パターンどうしの差の平均・95% 区間・基準より良かった Wafer の割合。
- **I 基準・D 基準**：学習 Shot の組ごとに、XY 多項式の基準モデル（I 最適の基準と同じ次数、候補の全 Mark で正規直交化）の情報行列 M から、I 基準 tr(M⁻¹)（平均予測分散に比例）と D 基準 det(M)^(−1/p)（p は項数）を求める。選び方（I 最適・ランダム・手動）によらず計算し、小さいほど良い計画。全候補を使うと I 基準 = p、D 基準 = 1。学習点が項数より少ないときは求めない。
  **全計測に対する I 効率・D 効率**：候補の全 Mark を計測した場合（I 基準 = p、D 基準 = 1）に対する効率。I 効率 = p / tr(M⁻¹)（全計測と比べて平均予測分散が何分の1倍か）、D 効率 = det(M)^(1/p)。0〜1 で、1 なら全計測と同じ、大きいほど良い。Excel の「Waferごと」「学習Shot」、計測マップの説明と Excel に出る。「4. 結果一覧」の「グラフ」で横軸を「I 基準と D 基準」にすると、2つの図を並べて、学習パターンの列ごとの推定誤差（上で選んだ指標・集計）を基準の値（Wafer の平均、対数目盛）に対して描く。「Wafer ごとの点も描く」で各 Wafer の点も重ねる。

比べられる手法

| 系統 | 選べるもの |
| --- | --- |
| GPR | fitrgp と同じ10カーネル、または ν を指定する Matérn（matern・ardmatern）× 説明変数（X,Y／X,Y,半径）× 質的変数（選んだもの）の8通りの扱い（使わない・同時推定・Backfitting・同時推定＋交互作用・加法カーネル・加法カーネル＋交互作用・混合・混合＋交互作用） |
| TPS | 平滑化つき薄板スプライン（λ は GCV）× 質的変数なし／Backfitting |
| RBF | ガウス型の動径基底関数＋1次多項式。広がりと平滑化は GCV で選択 |
| RBFe（仮） | 面内を領域に分けた TPS をつなぎ合わせる形状関数の GAM。領域の数（ハイパーパラメータ）× 質的変数なし／Backfitting（下の「RBFe（仮）」）。初期設定では使わない |
| Kriging | 通常 Kriging・Universal Kriging × バリオグラム（linear・gaussian・power・exponential・spherical）× 質的変数なし／Backfitting |
| GAM | 形状関数を項（X・Y、半径）ごとに P-spline・ガウス過程回帰のチェックで選び、チェックした組み合わせをすべて評価（λ は REML）＋ 選んだ質的変数。ガウス過程回帰のカーネル（exponential・squaredexponential・matern32・matern52・rationalquadratic・ν を指定する matern）も選べる |
| XY 多項式・RT モデル | 次数を指定 |
| Fringe Zernike | Fringe 番号の Zernike 多項式 Z1〜Z(k+1)²（次数 k を選ぶ。空白区切りで複数入れると比べる）を、Wafer 半径で割った座標（単位円）で最小二乗近似 × 質的変数なし／Backfitting。初期設定では使わない |

前処理として「XY 1次（並進・倍率・回転・直交度）を学習点で除いてから推定する」も選べます（実データで1次成分が大きいとき用。初期設定は使わない）。

### Overlay 補正の評価（推定誤差で Overlay 残差がどれだけ増えるか）

アライメントの推定値で露光の補正を求めると、推定誤差のぶん補正がずれ、Overlay の残差が増えます。その増え方を評価します。

| 場 | 求め方 |
| --- | --- |
| 実測値で補正した残差 | 全 Mark の計測値で補正モデルを当てはめ、計測値 − 補正量 |
| 推定値で補正した残差 | 学習 Shot は計測値、学習しなかった Shot は推定値で補正モデルを当てはめ（実際の運用と同じ）、その補正を実際の値（計測値）に当てた残差 = 計測値 − 補正量 |
| 推定による変化 | 推定値で補正した残差 − 実測値で補正した残差（= 2つの補正量の差） |

- 補正モデルは「2. 評価の設定」の **Overlay 補正の評価** で、次の3つの成分を組み合わせて選ぶ（X・Y 別々に最小二乗で当てはめる）。初期値は Wafer 成分 1次 ＋ Shot 共通成分 1次。

  | 成分 | 選択肢 | 中身 |
  | --- | --- | --- |
  | Wafer 成分 | なし・1次〜5次・式を入力 | Shot 中心の座標（Xmm・Ymm を Wafer 半径で割った値）の多項式。1次は並進・倍率・回転・直交度。「式を入力」なら下の dx・dy の式 |
  | Shot 共通成分 | なし・1次（k1〜k6）・式を入力 | Shot 内の座標（markXmm・markYmm）の補正式で、全 Shot で同じ係数。「式を入力」なら下の dx・dy の式。メーカー別の高次式（ASML・Canon・Nikon）は計算には残っているが画面では選べない（以前の設定 JSON の高次式は、画面に読み込むと 1次になる。同じ式は「式を入力」で書ける） |
  | Shot ごとの成分 | なし・並進（k1・k2）・1次（k1〜k6）・式を入力 | Shot ごとに別の係数を持つ補正。「式を入力」なら下の dx・dy の式（Shot 内の座標） |

- **補正の式を入力する**：Wafer 成分・Shot 共通成分・Shot ごとの成分で「式を入力」を選ぶと、それぞれの dx =・dy = の欄に補正量の式を書ける（X 成分は dx、Y 成分は dy の式で当てはめる）。式の x・y は、Wafer 成分では Shot 中心の座標、Shot 共通成分・Shot ごとの成分では Shot 内の座標。Shot ごとの成分の式は、Shot ごとに別の係数で当てはめる。
  - 書き方：項を + または − でつなぎ、各項は係数（k1 など英字で始まる名前、または数）と x・y のべき（`x`・`x^2`・`x*y`・`x^2*y`）を `*` でつなぐ。係数だけの項は定数（並進）。例：`k1 + k3*x + k5*y + k7*x^2 + k9*x*y + k11*y^2`。先頭の `dx =` は書いても書かなくてもよい。全角の英数字・−・×・²・³ も読める。
  - 係数の値は最小二乗で求めるので、係数の名前・符号・数は補正量に影響しない（項の形だけを使う）。同じべきの項は1つにまとめる。かっこ・`2x` のような `*` の省略・`x1` のような書き方は使えず、欄の下に赤字で理由を出して評価を始めない。べきは 9 まで。
  - 「説明」シートと結果の補正モデルに、入力した式をそのまま書く。設定 JSON の `overlay.waferUseFormula`（Wafer 成分に式を使うか）・`overlay.waferFormula`・`overlay.shotFormula`・`overlay.perShotFormula`（それぞれ `dx`・`dy` の文字列）。`overlay.shotCommon`・`overlay.perShot` は式なら `formula`。式の読み方は `alignest.parseCorrectionFormula`。
- 成分どうしで重なる項（Wafer 成分の定数と k1 など）や、Shot 内の Mark の位置が項より少なくて決まらない係数があっても、補正量（当てはめた値）は一つに決まるので、係数は求めずに補正量だけを使う。
- すべて「なし」なら評価しない。評価するときは、「4. 結果一覧」の指標に次の8つが加わる（どれも全 Mark の |平均| + 3σ [nm]、X・Y 別）：OVL 残差 実測値で補正、OVL 残差 推定値で補正、OVL 推定による変化、OVL 推定による増加（推定値で補正 − 実測値で補正）。手法 × 学習 Shot 数の表・グラフ・ワースト値・95%値・基準との比較で見られる。
- 実測値で補正した残差は Wafer だけで決まる（学習パターン・手法によらない）。推定による増加が小さい手法・学習 Shot 数ほど、推定しても Overlay が悪くなりにくい。
- 「5. Wafer ごとのマップ」の「図の内容」を **Overlay 補正** にすると、3つの場をベクトル（または X・Y の色）で並べ、下の行に |平均|+3σ を出す。灰色の四角は学習 Shot の Mark。
- 結果の Excel：「Waferごと」に8つの指標、「集計_統計量」と「集計_overlayEstimated_X」などに推定値で補正した残差・増加の集計、「説明」に補正モデルを出す。推定値の Excel には「Overlay残差」シート（全 Mark の3つの場、学習／評価 Shot の区分）を加える。
- 設定 JSON の `overlay.waferOrder`（0〜5）・`overlay.shotCommon`（`none`・`linear`・`asml`・`canon`・`nikon`・`formula`）・`overlay.perShot`（`none`・`translation`・`linear`・`formula`）。古い設定 JSON では評価しない（すべて「なし」）として読み込む。

### Wafer の平均の図と共分散楕円

「1. データの読み込み」の「Wafer マップ（計測値）」では、**平均・楕円の単位** で平均（共分散楕円）を求める単位を選びます：ALL（全 Wafer）・LotID・EqpId・Operation・Slot の偶奇・その他の列（標準の項目に対応づけなかった列）。選ぶと「表示する Wafer・平均」にその単位の平均（値ごと。値が1種類でも出す）が出て、最初の平均を表示します。その他の列は Mark ごとの値なので、その値の Mark だけを集めて平均します（Wafer の中で値が変わる列でもよい）。「5. Wafer ごとのマップ」の選択肢は、全 Wafer と、値が2種類以上ある LotID・EqpId・Operation ごとの平均、奇数・偶数の Slot がどちらもあるときの Slot の偶奇ごとの平均です。

### Slot の偶奇（Wafer ID のハイフンの後の番号）

Wafer ID の最後のハイフン（-）の後の整数（01〜25 など）を Slot 番号とし、奇数・偶数で傾向が違うかを確かめられます（`alignest.waferSlot`。ハイフンの後が数字でない Wafer は Slot なし）。

- 「1. データの読み込み」の平均・楕円の単位 **Slot の偶奇** で、奇数 Slot・偶数 Slot の平均の図（と共分散楕円）を切り替えて見る。
- 「5. Wafer ごとのマップ」の平均の選択肢（平均：Slot = 奇数・偶数）で、計測値・推定値・残差の平均を比べる（並べて比べる一覧にも足せる）。
- 「推定値と実測値の散布図」の色分け、「残差の箱ひげ図」と ANOVA の質的変数（Slot の偶奇）で、推定誤差が偶奇で違うかを見る。

「1. データの読み込み」の「Wafer マップ（計測値）」と「5. Wafer ごとのマップ」では、Wafer ごとの図のほかに、次の平均の図を選べます。

- **平均：全 Wafer**、**平均：LotID = …**、**平均：EqpId = …**、**平均：Operation = …**（LotID・EqpId・Operation は値が2種類以上あるときだけ出る）。
- 同じ座標（0.001 mm で丸める）の値を Wafer 間で平均して描く（X・Y それぞれ、有効な Wafer の平均）。「5. Wafer ごとのマップ」では、選んだ学習パターン・手法の計測値・推定値・残差（「図の内容」が Overlay 補正なら3つの補正残差）を Wafer ごとに求めてから平均する。学習 Shot の四角は最初の Wafer の位置。
- **共分散楕円**（なし・1σ・2σ・3σ、初期値 1σ）：座標ごとに Wafer 間の X・Y の分散と X・Y の相関（共分散）から楕円を作り、平均の矢印の先を中心に、矢印と同じ倍率で描く。楕円が細長いほど X・Y のばらつきが相関している。X・Y とも有効な Wafer が2枚以上の座標だけ描く。矢印（ベクトル）表示のときだけ。
- **ベクトルを描かない（楕円だけ）**：共分散楕円を描くとき、矢印を消して楕円だけにする（楕円の中心は平均の矢印の先のまま。「1. データの読み込み」「5. Wafer ごとのマップ」「Shot 重ね合わせ」）。楕円を描かない図では矢印を描く。
- **楕円の色**は X・Y の相関係数の絶対値 |r| = |共分散| / (σX・σY)（0〜1）。MATLAB の既定の色（parula：濃い青 = 相関なし → 黄 = 強い相関）で描き、図の右の目盛り（上に「|r|」）で読む。どちらかの分散が 0 の座標は |r| = 0 とする。
- **楕円と重ねる矢印は単色**：矢印の長さの色と楕円の色が混ざらないように、楕円を描く図の矢印は1色にする（「1. データの読み込み」は青、「5. Wafer ごとのマップ」は計測値・推定値が青、残差・推定による変化が橙）。楕円を「なし」にすると、矢印は長さ |v| の色に戻る。

### 質的変数の交互作用（データの読み込みで調べる）

「1. データの読み込み」の中のタブ **質的変数の交互作用** で、読み込んだ計測値の質的変数の効果と交互作用を調べます（`alignest.factorInteractions`）。説明変数（質的変数）と GPR のカーネル（質的変数の扱い）を選ぶ前の判断材料です。「この対応で読み込む」を押すと一度調べ、条件を変えて「評価する」で調べ直せます。

- 値：Wafer ごと・X・Y 別に、計測値から面内の傾向（Wafer 上の座標の多項式。次数は「除く面内の傾向」、初期値 3 次）を除いた残り（面内の形の違いを質的変数の効果と見誤らないため）。選んだ Wafer の値をまとめて調べる。
- 質的変数：Scan 方向・Mark 番号・Shot 行の奇偶と、選んだその他の列（初期値は「2. 評価の設定」で質的変数に選んである列）。
- 上の表（主効果）：変数ごとの一元配置の F・p 値・η² と、水準ごとの平均。下の表（交互作用）：2つずつの組の二元配置の分散分析（`alignest.stats.interactionTests`）。主効果（もう一方を入れたまま外す。Type II）の p 値、交互作用の F・p 値・偏 η²（交互作用で説明できる割合）。同じ分け方の組・点の無い水準の組が多い組は「調べられない」。
- 判定：p < 0.05 かつ 効果量（η²・偏 η²）≥ 0.01 なら「効果あり」「交互作用あり」（点が多いと小さな差でも p が小さくなるので、効果量でも判定する）。交互作用ありの行は色付き。
- 図：選んだ組・軸の交互作用の図（横軸は1つ目の変数の水準、線は2つ目の変数の水準ごとの平均）。線がほぼ平行なら交互作用は小さく、交わる・開くなら交互作用がある。
- **選び方の目安**（左の欄）：効果のある変数は質的変数に入れる候補、効果が小さい変数は入れなくてもよい見込み。交互作用があれば、GPR の「同時推定＋交互作用」「加法カーネル＋交互作用」「混合＋交互作用」も比べる。交互作用がなければ、交互作用の無い扱いで足りる見込み。

### Shot 重ね合わせ（Shot 内のベクトル場）

「1. データの読み込み」の **Shot 重ね合わせ** で、選んだ Wafer（複数可、読み込み直後は全 Wafer）のすべての Shot を Shot 内の座標（markXmm・markYmm）で重ね合わせます。

- 細い矢印：個々の Shot の計測値（色は長さ |v|。共分散楕円を描くときは淡い青の単色。「個々の Shot の矢印も描く」で消せる）。黒い太い矢印：Mark の位置ごとの平均。
- 共分散楕円（なし・1σ・2σ・3σ）：Mark の位置ごとの、Shot・Wafer 間の X・Y のばらつきと相関。平均の矢印の先を中心に描く。色は平均の図と同じく X・Y の相関係数の絶対値 |r|（MATLAB の既定の色、右の目盛り）で、Mark 番号の横に |r| の値も書く。
- **Wafer 成分を除く**（除かない・1次〜3次）：Wafer ごとに Shot 中心の座標の多項式（Overlay 補正の Wafer 成分と同じ当てはめ）を除いてから重ねる。Wafer 全体の傾向が大きいと Shot 内の成分が見えにくいので、1次を除くと Shot 内の倍率・回転などが読みやすい。
- **Scan 方向で分けた図も並べる**（Scan 方向のあるデータでは、読み込むとはじめからオン）：すべての Shot の図の右に、Scan 方向 1・2 の Shot だけを重ねた図を並べる。3つの図は同じ矢印の倍率・色の範囲で描くので、矢印の長さ・色をそのまま比べられる。Wafer 成分は Scan 方向で分ける前に、その Wafer のすべての Mark で当てはめて除く。Scan 方向はデータの Direction、または取り込みの「Scan 方向（Direction）が無い行に付ける値」で付けた値。選んだ Wafer に Scan 方向が無いときは、すべての Shot の図だけを描く。

### 推定値と実測値の散布図

「4. 結果一覧」の **推定値と実測値の散布図** で、手法・学習パターンの列・Wafer（すべて、または1枚）を選んで「描く」を押すと、評価点の実測値（横軸）と推定値（縦軸）の散布図を X・Y 別に描きます。

- 破線は y = x、赤い線は回帰直線（推定値 = a + b·実測値）。題名に相関係数 r、決定係数 r²、傾き b、RMSE、点数を出す。
- **色分け**：なし・Wafer・LotID・EqpId・Operation・Slot の偶奇・Scan 方向・Mark 番号・Shot 行の奇偶・外周と内側・象限・ファイルのその他の列（どれでも選べる。質的変数に選んでいなくてもよい）。水準が20を超えると凡例は出さない。
  - 外周・内側：Mark の半径が「外周とみなす Mark の半径 [mm]」（初期値 120 mm）以上なら外周（外周の RMSE と同じ境目）。
  - 象限：Mark の座標の偏角で第1〜第4象限に分ける（I 最適の4象限の制約と同じ分け方。軸の上は反時計回りに次の象限）。

### 計測する Shot をファイルの優先順で選ぶ

「2. 評価の設定」の選び方を **ファイルの優先順で指定** にし、**優先順のファイルを読み込む…** で Shot 番号と優先度の表（Excel・CSV）を読み込みます。

| 列 | 内容 |
| --- | --- |
| Shot 番号 | 名前に「shot」を含む列（無ければ1列目）。shotNo の値 |
| 優先度 | 名前に「prior」か「優先」を含む列（無ければ Shot 番号の次の列。無くてもよい）。1 = 必ず計測する、0 = 計測しない、それ以外・空 = 行の順に使う |

- 学習 Shot 数（開始・終了・刻み）ごとに、優先度 1 の Shot をすべて使い、残りを優先度 0 を除いてファイルの行の順に足す（「優先順 20 Shot」のような学習パターン）。同じ Shot が 0 と 1 の両方にあれば 0（計測しない）を優先する。
- 優先度 0 の Shot は学習に使わず、評価（推定して計測値と比べる）にだけ使う。
- 優先度 1 の Shot が学習 Shot 数より多いときはすべて使う。学習 Shot 数を計測率で決めることもできる。計測マップでは優先度 1 の Shot を「必ず計測する Shot」として描く。ファイルの Shot が足りない、または Wafer に無い Shot があるときは「3. 実行」の記録と Excel の「説明」に出す。
- 読み込んだ Shot 番号・優先度・ファイル名は設定 JSON（`sampling.priorityShots`・`priorityLevels`・`priorityFile`）に入るので、設定を保存すれば同じ順で評価し直せる。I 最適の制約（同心円・4象限・Scan 方向）は使わない。I 基準・D 基準は求める。

### 処理時間の記録

1 枚あたりの推定時間を手法選びの判断に使うときは、「2. 評価の設定」の **条件ごとの処理時間を記録する** をオンにします（初期値はオフ）。

- 記録するのは、1 枚の X・Y の推定（当てはめと評価点の予測）にかかった秒数。学習パターン（I 最適の計画など）を作る時間は含めず、Excel の「学習Shot」に別に出す（同じ配置の Wafer で使い回した場合は 0）。
- 各手法を最初に使う前に、予備の推定を1回して結果を捨てる（ファイルの読み込みなど初回だけの時間を除くため）。そのぶん全体の時間は少し延びる。
- 「4. 結果一覧」の指標に「処理時間 [秒/枚]」が加わり、手法 × 学習パターンの表・グラフ・基準との比較（時間の差の割合）で見られる。Excel には「処理時間」シート（平均・中央値・95%値・最大・合計・回数）を足す。
- 時間は PC の性能や同時に動いているソフトで変わる。手法どうしは同じ PC・同じ実行の中で比べる。

### 計測配置の選び方を比べる

「2. 評価の設定」で選び方を2つ以上選んで評価すると、「4. 結果一覧」の **計測配置の比較** で、手法を1つ選んで選び方どうしを比べられます（`alignest.layoutComparison`）。

- 図：選び方（I 最適・D 最適・ランダム・優先順・Mark 単位の I 最適・D 最適）ごとに、横軸（**計測する Mark の数**・**学習 Shot 数**・**D 効率**・**I 効率**）に対する指標（上の「指標」「集計」）の線を描く。人の選択・手動はパターンごとの点（名前つき）。計測する Mark の数で比べると、Shot 単位の計画と Mark 単位の計画を同じ計測の手間で比べられる。D 効率・I 効率（全計測に対する %、Wafer の平均）で比べると、計画の良さが同じなら誤差も同じくらいかを確かめられる。
- **エラーバー**：評価点ごとに、Wafer ごとの値のばらつきを縦の線で描く。「± 標準偏差（Wafer 間）」「95% 信頼区間（平均 ± 1.96 × 標準誤差。正規近似。集計が平均以外のときも同じ幅を目安として描く）」「Wafer の最小〜最大」から選ぶ（初期値は「なし」）。Wafer が1枚の列は標準偏差・信頼区間を描かない。
- 表：学習パターンの列ごとの選び方・学習 Shot 数・計測する Mark 数・指標の値・Wafer 間の標準偏差・I 基準・D 基準・I 効率・D 効率（Wafer の平均）。
- 人が選んだ配置を I 最適・D 最適と比べるときは、人の選択の Shot 数に近い学習 Shot 数を I 最適・D 最適の開始・終了・刻みに入れておく。

### 推定値と誤差の分布

「4. 結果一覧」の **推定値と誤差の分布** で、手法・学習パターンの列・Wafer（すべて、または1枚）を選んで「分析する」を押すと、評価点の残差（計測値 − 推定値）を調べます（選んだ Wafer の評価点をまとめて扱い、ランダムのくり返しも含む）。手法は Ctrl・Shift で **複数** 選べ、選んだ手法を並べて比べます（ヒストグラムは手法ごとの輪郭を重ね、検定の表は手法ごとの行、箱ひげ図は手法を色分け）。

- **ヒストグラム**：X・Y の残差の分布に、同じ平均・標準偏差の正規分布の曲線を重ねる（手法が2つ以上なら、共通の区間で手法ごとの輪郭を重ね、凡例に点数・平均・標準偏差）。手法ごとに色を変える。前に描いた手法とまったく同じ残差になる手法（例：Y にだけ違う質的変数を使う手法どうしの X）は輪郭が重なって見えなくなるので、破線にして凡例に「＝ 〇〇 と同じ」と書く。
- タブ「推定値と誤差の分布」「残差の箱ひげ図」「分布の比較」は、開いたときに最後に分析した内容で描き直す（開いていないタブに描いた図が出ないことがあるため）。
- **正規性検定**：点数・平均・標準偏差・歪度・尖度（過剰）と、Shapiro–Wilk（Royston の近似。3〜5000 点のときだけ）、Anderson–Darling（平均・分散を推定する場合の補正と p 値の近似）、Jarque–Bera の統計量と p 値。判定は Shapiro–Wilk の p 値（5000 点を超えるときは Anderson–Darling）が 0.05 未満なら「正規分布から外れている」。点数が多いと小さなずれでも p 値が小さくなるので、ヒストグラムと合わせて見る。
- **Shapiro–Wilk W が空欄になる理由**：近似が使える 3〜5000 点の範囲外、または残差がすべて同じ値のときは計算しない。そのときは W の欄に「— 6123 点（5000 点超）」のように理由を出し、下の説明にも書く（点数は選んだ Wafer の評価点の合計なので、Wafer を1枚に絞ると計算できることがある）。Anderson–Darling（8 点未満では計算しない）も同じ。推定値の Excel の「正規性検定」シートにも理由の列がある。
- **質的変数の ANOVA**：Scan 方向・Mark 番号・Shot 行の奇偶・工程（Operation）・装置（EqpId）・ロット（LotID）・Slot の偶奇と、質的変数に選んだファイルのその他の列ごとに、水準ごとの平均残差と F 検定。「一元配置」はその変数だけで分けた検定（η² は水準の違いで説明できる割合）、「ほかの変数で調整」は使える質的変数をすべて入れた主効果モデル（交互作用なし、Type II）からその変数を外したときの検定。同じ分け方になる変数（例：Scan 方向が Shot 行の奇偶と同じ）は区別できず、調整した検定は出さない。水準が1つしかない変数は検定しない。
- 検定は MATLAB 本体の関数（erfc・erfcinv・betainc）だけで計算する（Statistics and Machine Learning Toolbox は不要）。SciPy の shapiro・anderson・jarque_bera・f_oneway と照合済み（[tests/TestStatistics.m](tests/TestStatistics.m)）。

### 残差の箱ひげ図（ANOVA の中身を見る）

「推定値と誤差の分布」で「分析する」を押すと、同じ残差を「4. 結果一覧」の **残差の箱ひげ図（ANOVA）** に、質的変数（ANOVA と同じ：Scan 方向・Mark 番号・Shot 行の奇偶・工程・装置・ロット・その他の列）の水準ごとに X・Y 別に描きます。

- 箱は四分位範囲、中の線は中央値、ひげは箱から 1.5 × 四分位範囲まで、外の点は外れ値（MATLAB 本体の boxchart）。ANOVA は水準の平均を比べるので、水準ごとの平均を ◆ で重ねる。横軸の名前の後の（ ）は点数。
- 題名に一元配置の F・p 値・η²、下の欄に判定（5%）を出す。上の「質的変数」で変数を選び直せる。
- 「推定値と誤差の分布」で手法を2つ以上選んだときは、水準ごとに手法を色分けして並べる（凡例が手法。◆ の平均は描かない）。F・p 値と判定は下の欄に手法ごとに書く。

### 評価点の絞り込み（半径・Shot の条件で計算し直す）

「4. 結果一覧」と「5. Wafer ごとのマップ」の上の **評価点の絞り込み** で、評価点（学習しなかった Shot の Mark）を条件に合うものだけにして、指標を計算し直します（推定はやり直さない）。

- 条件：Mark の半径の範囲 [mm]（下限以上・上限未満。上限 Inf なら上限なし）、Shot（すべて・指定した shotNo だけ・指定した shotNo を除く）、Scan 方向（すべて・1・2）、最外周（含める・最外周の Shot だけ・最外周の Shot を除く）。組み合わせると、すべてを満たす点。
- 「絞り込んで再計算」で、表・グラフ・基準の手法との比較・Wafer ごとのマップ（図の点と下の指標）を描き直す。2つのタブの欄はそろう。「解除」で元に戻る。欄の下に「評価点 n / N 点」が出る。
- 計算し直す指標：R²・RMSE・MAE・外周と内側の RMSE・平均値・中央値に対する改善量と改善率・評価点の数（評価と同じ式。すべての点を残す条件なら評価のときと同じ値）。学習点・推定値・学習パターン・処理時間・I 基準・D 基準は変わらない。Overlay 補正の |平均|+3σ は、補正量を全 Mark で求めたまま、条件に合う Mark で求め直す。
- 推定値と誤差の分布・箱ひげ図・散布図・分布の比較・推定値の Excel は、次に「分析する」「描く」「比べる」「書き出す」を押したときに同じ条件で評価点を絞る（条件を変えたときは古い図を消す）。結果の Excel には「説明」に条件を書く。
- Excel から読み込んだ結果では、表・グラフは計算し直せない（評価点ごとの推定値が無いため）。推定値の Excel も読み込んでいれば、マップ・分布・散布図は絞り込める（最外周の条件は Shot の配置が無いので使えない）。

### 条件を追加して評価する

評価が終わった後（一時中断した後も）に、「2. 評価の設定」で **手法**・**説明変数の組（X,Y・X,Y,半径）**・**質的変数の組** を変えたり、**学習 Shot 数（計測率・手動の行・ランダムの繰り返し回数）** を増やしたりして、「3. 実行」の **条件を追加して評価（評価済みに足す）** を押すと、評価済みの結果に無い組み合わせ（Wafer × 学習パターン × 手法）だけを計算して、今の結果に足します。

- 評価済みの行はそのまま使う（推定し直さない）。足した手法は今の手法の後ろ、足した学習パターンは Shot 数（計測率）の順に並べ直す。最初からまとめて評価した結果と同じ値・同じ並びになる（[tests/TestFilterExtendTiming.m](tests/TestFilterExtendTiming.m)）。
- **質的変数の組を変えて足す**：質的変数（Scan 方向・Mark 番号・Shot 行の奇偶・その他の列。X・Y 別の選択も）を変えて押すと、質的変数を使う手法（GPR の質的変数あり・Backfitting・GAM など）を、新しい組で足す。足した手法の名前の最後に「質的変数：Scan 方向」のように付き、id は `_fs-<組>`（例：`TPS_XYR_backfit_fs-scan`、X・Y で違えば `_fs-scan+mark~scan`）で終わる。手法は自分の組で推定するので、評価済みの手法（最初に評価したときの組）と並べて比べられる。質的変数を使わない手法（XY 多項式など）は同じ結果なので足さない。結果の「説明」の「追加した条件」に、足した組と元の組を書く。
- 推定の結果を変える設定（データの読み込み・学習 Shot の選び方と制約・乱数の種・必ず計測する Shot・評価の条件（外周の半径・1次を除く・異常値の除外・処理時間の記録）・Overlay 補正・手法の細かい設定）を変えたときは追加できない（どれが違うかを表示する。「評価を始める」で計算し直す）。足すものが無いときもそう伝える。
- 追加の評価も「一時中断」「続きから再開」ができる。計算時間は前と後を足す。結果の Excel の「説明」に「追加した条件」を書く。

### 処理時間の内訳

「4. 結果一覧」の **処理時間の内訳** で Wafer・学習パターン・手法（複数可）・測る回数を選んで「測る」を押すと、その条件の1回分の処理を段階に分けて測り、手法ごとの積み上げ横棒（左：秒、右：割合）と表に出します（評価の結果は変えない）。

| 段階 | 中身 |
| --- | --- |
| 学習パターンの作成（最適マップ） | I 最適の交換法・ランダム・優先順で学習 Shot を選ぶ（`alignest.planTrainingShots`） |
| 異常値の判定 | 学習データの異常値を除く設定のときだけ |
| 推定の準備 | 学習点・評価点の選び出し、XY 1次を除く設定ならその当てはめ |
| 学習（当てはめ） | モデルの当てはめ（ハイパーパラメータ・平滑化の強さの推定を含む） |
| 推論（評価点の推定） | 全評価点を推定した時間と、評価点を1点にした時間の差 |
| 評価指標の計算・Overlay 補正の評価 | R²・RMSE などと、Overlay 補正の評価（評価するときだけ） |

- 学習と推論は1つの関数で続けて計算する手法が多いので、推論は上の差で求める（差が負なら 0）。測る回数の中央値を使い、初めに1回、初回だけの時間を除くための予備の計算をして捨てる。
- 評価では学習パターンを同じ配置の Wafer・手法で使い回すので、評価全体に占める作成の割合はこの図より小さい（模擬データ・I 最適 15 Shot・初期配置 10 では、作成 約 1.6 秒に対して TPS・多項式の推定は 0.01 秒以下、GPR は 約 0.03 秒）。

### Wafer ごとのマップで条件を並べて比べる

「5. Wafer ごとのマップ」の右の **比べる条件** に、上で選んだ Wafer・平均、学習パターン、手法を「上の条件を一覧に追加」で足すと、並べ方が「一覧の条件を並べて比べる」になり、最大 6 条件を並べて描きます。

- 並べた図はすべて「並べて比べる値」（計測値・推定値・残差。図の内容が Overlay 補正なら2つの補正残差・推定による変化）で、矢印の倍率・色の範囲・矢印の色の範囲をそろえる（そのまま見比べられる）。題名に条件と RMSE（X・Y）を出す。
- Wafer どうし・手法どうし・学習パターンどうし・平均（全 Wafer・LotID など）を自由に組み合わせられる。「選んだ条件を外す」「一覧を空にする」で減らす。並べ方を「1つの条件」に戻すと、今までの3枚（計測値・推定値・残差）の表示になる。
- **Shot の枠を Scan 方向で色分け**：Shot の枠を Scan 方向の色（既定は緑 = 1、紫 = 2）で描き、枠の左上に ▲（上向き）・▼（下向き）を付ける（色だけに頼らない）。「1. データの読み込み」の Wafer マップにも同じ選択がある。Shot レイアウトの塗りも同じ色を薄くした色。色と向きは下の「Scan 方向の向きと色」で変えられる。
- **同心円の区切り（制約）を描く**：評価で I 最適・ランダムの同心円の制約を使ったとき、区切りの半径（Shot 中心の半径 [mm]）を橙の一点鎖線と半径の数字で描く（計測マップ・データの Wafer マップも同じ）。

### Shot スタックマップ

「5. Wafer ごとのマップ」の右の並べ方で **Shot スタックマップ（全 Shot を重ねる）** を選ぶと、上で選んだ条件（Wafer・平均 × 学習パターン × 手法）の評価点を、Shot 内の座標（markXmm・markYmm）で1つの Shot に重ねて描きます（`alignest.plot.shotStackMap`）。

- 値は「並べて比べる値・スタックする値」（計測値・推定値・残差。Overlay 補正なら補正残差・推定による変化）。平均（全 Wafer・LotID など）を選ぶと、その Wafer すべての Shot を重ねる。
- ベクトル：Shot ごとの矢印を薄い色で重ね、Mark の位置ごとの平均を濃い矢印で描く。X・Y（色）：点ごとの値を色で描き（同じ位置の点は少しずつ横にずらす）、位置ごとの平均を少し下に ■ で描く。Shot の外形は破線。
- **分け方**：「すべての Shot を1つに重ねる」「Scan 方向ごと」「Shot 行の偶奇ごと」「Scan 方向 × 行の偶奇ごと」（4 枚）から選ぶ。点の無い組は描かない。矢印の倍率（0 = 自動。Shot の短い辺の 18% が大きさの 95% 点）と色の範囲は、並べた図で共通。
- **計測値・推定値・残差を並べる**：オンにすると、3つの値（Overlay 補正なら2つの補正残差・推定による変化）を列に、分け方の組を段にして並べる（例：Scan 方向ごとなら 2 段 × 3 列）。矢印の倍率と色の範囲は計測値（Overlay 補正では推定値で補正した残差）に合わせてそろえるので、そのまま比べられる。図が 6 枚より多いときは、分け方を減らすよう知らせる。
- Excel から読み込んだ推定値には Shot 内の座標が無いので、このセッションで評価した結果で描く。

### Scan 方向の向きと色

「2. 評価の設定」の下の **表示：Scan 方向** で、図の描き方を変えられます（推定の結果は変わらない。評価済みの結果の再開・条件の追加もそのまま使える）。

- **Scan 方向 1・2 の向き**：「1 = 上向き（▲）、2 = 下向き（▼）」（初期値）または「1 = 下向き（▼）、2 = 上向き（▲）」。Shot の配置・計測マップ・Wafer ごとのマップ・Shot スタックマップの印と凡例（例：「Scan 1（▼ 下）」）に使う。
- **色**：Scan 方向 1・2 の色を「色を選ぶ…」で選ぶか、16進数（例：#1A9447）で入れる。「既定の色（緑・紫）に戻す」で戻す。設定 JSON では `display.scan1Up`・`display.scan1Color`・`display.scan2Color`（RGB 0〜1）。

### Matérn の ν・spherical バリオグラム・GAM の形状関数

**GPR の Matérn カーネルの ν（次数）**

- 「カーネル」で **matern（ν を指定）**・**ardmatern（ν を指定）** を選び、「Matérn の ν」に値を空白区切りで入れる（例：`0.75 1 2 3.5`）。値ごとに別の手法として比べる（id は `GPR_matern_nu1.2_XYR_basis` のように ν を含む）。初期値は 2。
- 式は σf² · 2^(1−ν)/Γ(ν) · (√(2ν) r)^ν · K_ν(√(2ν) r)（r は長さスケールで割った距離、K_ν は第2種変形ベッセル関数）。ν が大きいほど滑らかで、ν = 0.5・1.5・2.5 で exponential・matern32・matern52 と同じ式になる（テストで 1e−12 以内の一致を確認）。使える範囲は 0 < ν ≤ 50。
- ハイパーパラメータ（長さスケール・σf・σn など）は他のカーネルと同じく対数周辺尤度の最大化で推定する。ν は推定せず、入れた値に固定する。勾配は解析的に求め、数値微分との一致をテストで確認。MATLAB 本体の `besselk`・`gammaln` を使う（Toolbox 不要）。

**Kriging の spherical（球形）バリオグラム**

- 「バリオグラム」の **spherical** を選ぶ。γ(d) = psill·(3d/(2·range) − d³/(2·range³)) + nugget（d ≤ range）、psill + nugget（d > range）。PyKrige の spherical と同じ式・初期値・範囲・soft_l1 損失で当てはめる。
- 球形モデルは説明変数が3次元までなら正定値が保証される。このツールの説明変数（X,Y・X,Y,半径）はどちらも3次元以下。

**GAM の形状関数（スプライン・ガウス過程回帰）**

- 「GAM」の下の **形状関数** で、X・Y（2次元の項）、半径の項ごとに **スプライン**（従来の P-spline）と **ガウス過程回帰** のチェックを付ける。チェックした組み合わせをすべて評価する（例：X・Y で両方、半径でスプラインだけなら2通り）。項ごとに1つ以上選ぶ。半径の項は説明変数が X,Y,半径 のときだけ使う。初期値はすべてスプライン（従来と同じ結果）。
- **ガウス過程回帰のカーネル**：形状関数の下の「ガウス過程回帰のカーネル」で、exponential・squaredexponential・matern32・matern52（初期値）・rationalquadratic（α = 1 に固定）・matern（ν を指定。右の欄に ν を空白区切り）をチェックで選ぶ。ガウス過程回帰の項がある組み合わせを、チェックしたカーネルごと（matern は ν ごと）に評価する（スプラインだけの組はカーネルで分けない）。式は GPR のカーネルと同じ（`alignest.models.stationaryKernel`）。長さスケールは項ごとに1つ（ARD は使わない）。
- ガウス過程回帰の項は、選んだカーネルを節点で近似した低ランクのガウス過程：s(z) = 線形部分 + Σ b_k k(z, κ_k)、罰則 bᵀK(κ, κ)b。線形部分（X・Y の項は x・y、半径の項は r）は罰則なし（スプラインの2階差分の罰則と同じく、1次の変化は罰しない）。節点は X・Y が [−1, 1]² の 7 × 7 格子のうち Wafer の内側、半径は [0, 1] の 10 点。
- 罰則の強さ λ は、スプラインと同じく REML で項ごとに選ぶ。長さスケールは候補（0.15・0.3・0.6。Wafer 半径で割った単位）から、項ごとに順に REML の基準が最も小さいものを選ぶ（候補の数だけ当てはめ直すので、スプラインより時間がかかる）。選んだ長さスケールは Excel の「Waferごと」のハイパーパラメータに `gpLength_<項>_<軸>` として残る。
- id は、ガウス過程回帰にした項を `_gp-` の後に付ける（例：`GAM_XYR_gp-xy-r`）。matern52 以外のカーネルは最後に `_<カーネル>` を付ける（例：`GAM_XYR_gp-xy_matern32`、`GAM_XYR_gp-xy_matern_nu1.5`。matern52 は以前と同じ id）。手法の表示名にはカーネルを（）で付ける。
- 詳細設定は JSON の `methods.gpr.maternNu`、`methods.gam.shapes`（`xy`・`r` に `spline`・`gp` の並び）、`methods.gam.gpKernels`・`gpMaternNu`、`methods.options.gamGpLengthScales`・`gamGpKnots`・`gamGpGridKnots`。古い設定 JSON では ν は 2、形状関数はすべてスプライン、GAM のカーネルは matern52 になる。

### RBF と TPS・Kriging の Backfitting

「2. 評価の設定」で **RBF（ガウス型・平滑化つき）** を選ぶと、RBF を手法比較に追加できます。説明変数は既存手法と同じ XY／XYR です。

TPS・RBF・Kriging（通常）・Universal Kriging・Fringe Zernike の右側では、それぞれ **質的変数なし／Backfitting／なし・Backfitting を比較** を選べます（Fringe Zernike の Backfitting は `FringeZ_k<次数>_backfit`、設定 JSON は `methods.zernike.factorModes`）。両方を選ぶと、同じ学習 Shot でそれぞれの結果が出ます。

- Backfitting は、選んだ質的変数（下の「質的変数を選ぶ」）を固定効果として扱う。質的変数の効果を除いた残差から空間成分を推定し、質的変数の効果を更新する。
- TPS・RBF は平滑化（RBF は広がりも）を、Kriging はバリオグラムを残差から選び直す。学習点で平滑化を固定した内側の交互反復は収束値を直接計算し、外側を最大20回、変化が 0.001 nm 未満になるまで繰り返す。評価点の計測値は当てはめにも設定選択にも使わない。
- 収束しなかった場合は「3. 実行」の記録と Excel の「説明」に通知し、最終反復の結果を残す。「Waferごと」の「最適化の収束」は false になる。有効自由度には質的変数と空間成分の両方を含める（最終パラメータ固定時の値）。
- RBF の基底は `exp(-r² / (2ℓ²))`。Wafer 半径で正規化した説明変数の距離で、ℓ の初期候補は 0.05・0.1・0.2・0.4・0.8・1.6。平滑化と合わせて学習データの GCV（一般化交差検証）が最小の候補を使う。選択した値は Excel の「ハイパーパラメータ」に残る。
- 詳細設定は JSON の `methods.options.rbfLengthScales`、`rbfLog10Lambda`（最小・最大・候補数）、`backfitMaxIterations`、`backfitToleranceNm` で指定する。RBF の候補や Backfitting の反復が増えると計算時間も増える。
- 従来の設定と結果を再現できるよう、「推奨の組み合わせ」は従来の9手法を維持する。RBF と追加の Backfitting は個別に選ぶか「すべて選ぶ」で追加する。古い設定JSONでは RBF はオフ、TPS・RBF・Kriging の質的変数は「なし」になる。

### RBFe（仮）：領域分割 TPS の GAM

「2. 評価の設定」の「比べる手法」の **RBFe（仮）** は、TPS を形状関数とする GAM です。ただし全面で1つの TPS ではなく、面内を領域に分けて領域ごとに TPS を当てはめ、つなぎ合わせます（`alignest.models.rbfeSetup`・`rbfeFitPredict`）。

1. 学習点の Wafer 上の位置を **領域の数 K**（ハイパーパラメータ）のまとまりに分ける（k-means。初期値は決まった選び方なので、同じ学習点なら毎回同じ領域）。
2. まとまりの中心のまわりの円（半径 = まとまりの点の中心からの最大距離 × 1.5。隣の領域と重なる）の学習点で、領域ごとに平滑化つき TPS を当てはめる（λ は領域ごとに GCV。説明変数は TPS と同じく X,Y または X,Y,半径）。領域の学習点が 10 点より少なければ半径を広げ、学習点が K × 10 点に足りなければ K を減らす。
3. 重なる所は滑らかな重み（Wendland の関数 (1 − t)⁴(4t + 1) を和が 1 になるように割った重み）で混ぜてつなぐ。どの領域にも入らない点（外挿）は、中心が最も近い領域の TPS を使う。
4. 質的変数は、右の「質的変数なし／Backfitting」で選ぶ（初期値は Backfitting。GAM として質的変数の効果を形状関数と交互に推定する）。

- 領域の数は空白で区切って複数入れると、領域の数ごとに比べる（例：`4 9`。1〜25）。1 は全面で1つの TPS と同じ（テストで確認）。
- 手法の id は `RBFe_k<領域の数>_<説明変数>`（Backfitting は `_backfit`）。結果の「ハイパーパラメータ」の列に、使った領域の数（`rbfeRegions_X`）と λ の平均（`log10Lambda_X`）が出る。
- 設定 JSON は `methods.rbfe.enabled`・`regions`・`factorModes`、細かい設定は `methods.options.rbfeOverlap`（円の半径の倍率、初期値 1.5）・`rbfeMinPoints`（領域ごとの学習点の最小数、初期値 10）。名前は仮です。

### 質的変数を選ぶ

「2. 評価の設定」の「比べる手法」の **質的変数** で、推定に使う質的変数を選びます。GPR（扱い方が「使わない」以外）・GAM と、Backfitting を選んだ TPS・RBF・Kriging に使います。

| 質的変数 | 水準 | 初期値 |
| --- | --- | :---: |
| Scan 方向 | Direction の列、または「Scan 方向が無い行に付ける値」で付けた 1・2。値の無い Wafer では使わない | オン |
| Mark 番号 | markNo | オン |
| Shot 行の奇数・偶数 | 下の「Shot 配列の行の奇数・偶数」 | オフ |
| ファイルのその他の列 | 標準の項目に対応づけなかった列の値（文字・数字。複数選べる）。値が空の Mark がある Wafer では、その列を使わない | なし |

- 選んだ変数は、同時推定・Backfitting・GAM では固定効果（効果コード）、加法カーネルでは変量効果（項 τ²·[水準が同じ]、ハイパーパラメータ名は `tau_scan`・`tau_mark`・`tau_row`・`tau_col_<列名>`）になる。混合は Mark 番号を変量効果、それ以外を固定効果にする。「交互作用あり」は選んだ変数の全ペアを含む。
- 変数どうしが同じ分け方になる場合（例：Scan 方向と Shot 行の奇偶）は、固定効果の重なる列を除く。学習点で水準が1種類しかない変数は効果を推定しない。
- その他の列の一覧は、データを読み込むと出る。設定ファイルで選んである列がデータに無いときは「（データに無い）」と表示し、評価を始めない。
- **X 成分と Y 成分で別に選ぶ**：「Y 成分は別に選ぶ」にチェックすると、下の「Y 成分」の行と右の「ファイルのその他の列（Y 成分）」で、Y 成分の推定に使う質的変数を X 成分とは別に選べる（チェックした直後は X 成分と同じ選択）。チェックしなければ、X 成分の選択を Y 成分にも使う（従来と同じ）。どちらかの成分で選んだ列がデータに無ければ、評価を始めない。
- 選択は設定 JSON の `factors.scan`・`factors.mark`・`factors.shotRowParity`・`factors.columns`（X 成分）、`factors.separateY` と `factors.y.scan`・`factors.y.mark`・`factors.y.shotRowParity`・`factors.y.columns`（Y 成分）と、結果 Excel の「説明」に保存される（X・Y で違えば「X 成分：…／Y 成分：…」）。古い設定 JSON では Scan 方向・Mark 番号を使い、その他の列は使わない（従来と同じ）。Y 成分の選択が無い設定 JSON は、Y 成分も X 成分と同じにする。
- 残差の ANOVA は、選択によらず Scan 方向・Mark 番号・Shot 行の奇偶・工程・装置・ロットを調べ、質的変数に選んだその他の列も加える。
- **1つだけ使う手法も比べる**：「チェックした質的変数を1つだけ使う手法も比べる」をオンにすると（初期値はオフ）、質的変数を使う手法（GPR の質的変数あり・Backfitting・GAM など）ごとに、チェックした変数を1つだけ使う手法を足して評価する（全部を使う手法も残す）。手法の名前の最後に「質的変数：Scan 方向だけ」のように付き、id は `_1f-scan`・`_1f-mark`・`_1f-row`・`_1f-列:<列名>` で終わる。X・Y で別に選んだときは、その成分で選んだ変数だけを使う（選んでいない成分は質的変数なし）。チェックした変数が2つ以上のときだけ足す。設定 JSON では `factors.evaluateSingles`。条件の追加（「条件を追加して評価」）で後から足せる。

### Shot 配列の行の奇数・偶数

「質的変数」の **Shot 行の奇数・偶数** を選ぶと使います。初期値はオフです。

- 各 Wafer・測定日時について、Shot 中心の `Ymm` を大きい順（上から）に並べ、1行目を奇数行、2行目を偶数行として扱う。同じ Y 座標の Shot とその Mark は同じ分類になる。座標は変換後の mm を小数点以下3桁に丸めて判定する。
- Excel の行番号や `shotNo` の奇偶ではない。半径で点を除く前の入力座標を使うため、有効半径を変えても分類は変わらない。ただし、入力に一切含まれない Shot 行は数えられない。欠落行を含む装置側の行番号を再現する機能ではない。
- 扱い方は上の「質的変数を選ぶ」のとおり（混合では固定効果）。

## 未知の座標の推定

「6. 未知の座標の推定」では、学習データ（計測値）から、計測していない座標の値を推定します（`alignest.predictTargets`）。新しい Mark の位置の値を全 Shot で見積もる、Wafer 上の任意の点の値を求める、といった使い方です。

1. **推定する点を決める**（左の表。1行1点）
   - **Excel・CSV から読み込む…**：1行目が見出しの表（`未知の座標` シートがあればそれ、無ければ書き出した推定値の `推定値` シート、それも無ければ最初のシート）。見出しは計測データと同じ名前で、大文字・小文字は区別しない。読み込むと表を置き換える。

     | 見出し | 必須 | 中身 |
     | --- | --- | --- |
     | Xmm・Ymm | ○ | Shot 中心の Wafer 上の座標 [mm]（markXmm・markYmm が空欄・0 なら点そのものの座標） |
     | markXmm・markYmm | | Shot 中心から見た点の位置 [mm]（空欄は 0） |
     | markNo | | Mark 番号（学習データに無い番号でもよい。空欄でもよい） |
     | shotNo | | Shot 番号（空欄なら点を含む Shot を座標から探す） |
     | Direction | | Scan 方向 1・2（空欄なら点の Shot の Scan 方向） |
     | 名前（Name・ID でも可） | | 点の名前（空欄は P1, P2, …） |

   - **画面で作る**：「行を追加」で1行足して書き込む（全角の数字も読む）。「全 Shot に置く」は、Shot 内の位置（X・Y [mm]）と Mark 番号を入れて、選んだ Wafer の全 Shot の同じ位置に点を置く（新しい Mark の位置）。「格子で置く」は、間隔と半径 [mm] を入れて Wafer 上の格子の点を置く（上限 20,000 点）。どちらも表に足す。「選んだ行を削除」「すべて消す」で減らす。数でない欄・Xmm・Ymm の空欄は、表の下に行の番号を赤字で出す。
2. **条件を選ぶ**：Wafer と学習データ（**計測値のある全 Mark**、または評価した後なら **学習パターン**：その Wafer の学習 Shot（Mark）だけで推定）は、どちらも Ctrl・Shift で **複数** 選べ（Ctrl + A ですべて）、選んだ Wafer × 学習データの組み合わせごとに **一括で推定** する。手法は「2. 評価の設定」で選んだ手法から1つ。手法の質的変数・XY 1次を除く・異常値の除外は「2. 評価の設定」の今の設定のとおり。
3. **「推定する」**：評価と同じ計算（`alignest.estimateWafer`）で、点を計測値の無い Mark として足して推定する。学習しなかった Mark と同じ点を渡すと、評価の推定値と一致する（テストで確認）。
4. **結果を見る**：上のメッセージ（外挿・Wafer の外・学習に無い Mark 番号・Scan 方向が分からない点。組み合わせが複数なら外挿の数をまとめる）、「図」（**図・補正に出す組み合わせ** で選んだ Wafer × 学習データの推定値の矢印または X・Y の色、学習点、学習点の範囲＝凸包の破線、外挿の点の ×）、「推定値の表」（すべての組み合わせ。Wafer・学習データの列つき。外挿・Wafer の外の行は色付き。「メモ」に点ごとの注意）。「推定値を Excel に書き出す…」で「推定値」「説明」シートに保存する（「推定値」シートは読み込む表と同じ見出しなので、そのまま点として読み直せる）。
5. **重ね合わせ補正値を計算する**（推定した後）：組み合わせごとに、**元の実測値**（学習点の計測値）・**学習しなかった Mark の推定値**（学習パターンのとき）・**未知の座標の推定値**（Wafer の外の点を除く）をまとめて、「2. 評価の設定」の Overlay 補正のモデル（Wafer 成分・Shot 共通成分・Shot ごとの成分）を X・Y 別に最小二乗で当てはめる（`alignest.targetOverlayCorrection`）。「重ね合わせ補正」のタブに、点の種類ごとの補正前の値・補正後の残差の |平均| + 3σ と、補正値（係数。mm の座標での値で、単位は nm/mm^べき。1次は nm/mm = ppm）を出す。成分どうしで重なる項（例：Wafer 成分の定数と Shot 共通成分の k1）や、点が少なくて決まらない項は、前の項（Wafer → Shot 共通 → Shot ごと）に含めて 0 とし、「メモ」に書く（補正量は変わらない）。未知の座標の点は、点を含む Shot の Shot 内の座標で当てはめる（どの Shot にも入らない点は、その点だけの Shot として扱う）。Excel には「補正値」「補正の残差」「補正に使った点」シートを足し、「推定値」シートに未知の座標の点ごとの **補正量X・Y** と **補正後の残差X・Y** の列を足す。まだ計算していない（または計算した後に補正モデルを変えた）ときは、書き出すときに今の補正モデルで計算する（「説明」の「重ね合わせ補正」に、補正モデルと「書き出すときに計算した」を書く）。「補正値」のタブの「補正値を Excel に書き出す…」でも同じファイルを書き出す。1変数の推定・補正モデルがすべて「なし」のときは補正値を書かない（「説明」に理由）。
   - **補正のモデル**のタブで、補正の式（Wafer 成分・Shot 共通成分・Shot ごとの成分と dx・dy の式）をこのタブのまま変えられる。「2. 評価の設定」の Overlay 補正と同じ設定で、どちらで変えても同じになる（評価の Overlay 補正の評価にも使う）。式の誤りは欄の下に出る。補正値を計算した後にモデルを変えると、「補正値」「補正残差のマップ」の上に「計算し直してください」と出す。「このモデルで重ね合わせ補正値を計算する」で計算し直す。
   - **補正残差のマップ**のタブで、選んだ組み合わせの **補正後の残差**（または補正量・補正前の値）を Wafer 上のベクトル（矢印）、または X・Y の色で描く（`alignest.plot.correctionMap`）。「点」で、すべての点・未知の座標だけ・実測値（学習点）だけ・学習しなかった Mark の推定値だけに絞れる。四角は実測値の点、◇ は未知の座標の点。題名と下の欄に、描いた点の |平均| + 3σ（X・Y）を出す。「図を画像で保存…」で PNG に保存する。

- **Wafer の外**：Wafer 上の座標（x = Xmm + markXmm、y = Ymm + markYmm）が 300 mm Wafer の外（半径 150 mm 以上。境界の上も外）の点は推定の対象外とし、推定値を X・Y とも 0 にする（外挿には数えない。図には描かない）。表の「外挿・対象外」に「Wafer の外（対象外）」と出し、上のメッセージに件数を出す。
- **外挿**：学習点（X・Y のどちらかで学習に使った Mark）を囲む凸包の外に 0.5 mm より離れた点。画面の上に「⚠ 外挿：N / M 点が学習点の範囲の外にあります（最大 d mm 外）」と出し、表の「外挿」「範囲の外 [mm]」（凸包までの距離）と図の × 印で示す。外挿の点も推定値は出すが、学習点から離れるほど信頼できない。
- **学習に無い Mark 番号**：学習点に無い Mark 番号（新しい Mark）・空欄の点は、Mark 番号の効果を全 Mark の平均として推定する（効果コードは 0、加法カーネルは同じ Mark の学習点が無い）。その旨をメッセージに出す。Mark 番号を使わない手法（質的変数を使わない GPR・XY 多項式・RT・Fringe Zernike など）は位置だけで推定する。
- **点の Shot と Scan 方向**：shotNo が無い点は、点を含む Shot（Shot 中心 ± Shot の大きさの半分）を探し、その Scan 方向・行の奇偶を使う。Shot の外の点は Scan 方向の効果を平均とする（質的変数に Scan 方向を使う手法のとき、メッセージに件数を出す）。

### 書き出した結果を読み込む

「4. 結果一覧」の **結果を読み込む…** で、「結果を Excel に書き出す…」で書き出したファイル（.xlsx）を選ぶと、その結果を画面に戻します（`alignest.importResults`）。計測ファイルを読み込まなくても使えます。

- 「Waferごと」シートから結果の表を、「学習Shot」から学習パターン（shotNo・I 基準・D 基準）を、「説明」から作成日時・計算時間・計算の注意を、「設定」から評価の設定（手法の中身・質的変数など）を作り直す。
- 表（手法 × 学習パターン。集計・指標を変えられる）、グラフ（学習 Shot 数、I 基準・D 基準。エラーバー・Wafer ごとの点も）、基準の手法との比較が、書き出す前と同じに出る。グラフは画像で保存できる。
- 評価結果の Excel には推定値そのものが無いので、それだけでは Wafer マップ・推定値と誤差の分布・散布図・分布の比較は使えない。次の **推定値の Excel を読み込む…** で、同じ評価から「推定値を Excel に書き出す…」で書き出したファイルも読み込むと使える（または計測ファイルを読み込んで「3. 実行」で評価し直す）。読み込んだ結果をもう一度書き出す必要はない（元のファイルをそのまま使う）。
- 画面の上に、読み込んだファイルと作成日時を出す。計測ファイルを読み込み直す・評価し直すと、読み込んだ結果は消える。

**推定値の Excel を読み込む…**（評価結果を読み込んだ後に使える。`alignest.importEstimates`）

- 推定値と誤差の分布（ヒストグラム・正規性検定・ANOVA）・散布図（色分けも。その他の列は質的変数に選んだ列だけ）は、計測データから計算したときと同じ値になる。
- 分布の比較：Wafer 全面・学習の分布は、推定値の Excel の学習データの行（「区分」が学習）から作る（Wafer ごとに最初の学習パターンの行で全面を数える）。学習データの行が無い以前の版のファイルでは、全面・学習の分布は出さない。
- Wafer ごとのマップ：Wafer ごと・平均（全 Wafer・LotID・EqpId・Operation）の計測値・推定値・残差と、Overlay 補正の3つの場（「Overlay残差」シートがあるとき）。平均の図は共分散楕円も描く。Shot 中心の座標は Excel に無いので Shot の枠は描かない。
- 読み込んだ推定値はもう一度書き出せない（元のファイルを使う）。評価結果の Excel を読み込み直すと、推定値の Excel は外れる。

- このアプリで書き出したファイルだけを読む（必要な列：Wafer・学習パターン・列・手法・手法の識別子）。以前の版で書き出したファイルで無い列（改善率・I 効率など）は空になる。

## 計算時間の目安

「2. 評価の設定」の下と「3. 実行」に出す目安は、**1条件（Wafer × 学習パターン × 手法 の1つ）あたり 2 秒 × 条件の数** です（`alignest.estimateRunSeconds`）。手法や学習 Shot 数で実際の時間は違います（M1 Mac・模擬データでは多くの手法が 1条件 0.1 秒以下、I 最適の学習パターンは同じ配置の Wafer で1回だけ約1〜4秒）。ただし ν を指定した Matérn のカーネル（GPR の matern・ardmatern、GAM のガウス過程の matern）を使う手法はベッセル関数の計算のぶん遅いので、**1条件 6 秒（3 倍）** で見積もります。ν を複数入れると ν ごとに手法が増え、その数も目安に入ります（目安の欄に「うち ν を指定した Matérn の手法 N 種類」と出る）。計算中の「残り」は、実際にかかった時間から出します。

### 交換法の初期配置の数と計算時間

制約付き I 最適の学習パターンは、交換法を「初期配置の数」だけ別の初めの組からくり返し、最も I 基準の小さい組を使います。**時間は初期配置の数にほぼ比例** し、初期配置 1 つあたり **約 0.01 秒 × 学習 Shot 数** です（下の表から。候補 Shot 数が多いほど長くなる）。「2. 評価の設定」の初期配置の数の下に、今の設定での目安（学習パターン1つ・全部）が出ます（`alignest.exchangeSecondsGuide`）。

1 Wafer・1 学習パターンを作る時間 [秒]（同梱の模擬データ：候補 99 Shot・396 Mark、基準モデル XY 5次（21 項）、反復の上限 300。MATLAB R2022b・Apple M1 の Mac（Intel 版を Rosetta で実行）で3回測った中央値、2026-10-23）

| 初期配置の数 | 学習 10 Shot | 20 Shot | 30 Shot | 40 Shot |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 0.17 | 0.22 | 0.33 | 0.34 |
| 5 | 0.43 | 0.89 | 1.4 | 1.8 |
| 10（初期値） | 0.73 | 1.9 | 2.7 | 3.8 |
| 20 | 1.5 | 3.6 | 5.6 | 9.3 |
| 30 | 2.4 | 5.9 | 13 | 13 |
| 50 | 4.0 | 9.3 | 15 | 21 |
| 100 | 8.0 | 21 | 36 | 42 |

- 例：初期値 10 を 30 にすると約 3 倍、100 にすると約 10 倍。評価全体では「学習パターンの数 × 配置の違う Wafer の数」だけかかる（候補 Shot と Mark が同じ Wafer では使い回すので、模擬データ 5 枚では1回分）。
- 良さ（I 基準。小さいほど良い）は、この模擬データでは 10〜20 を超えるとほとんど変わらなかった（例：20 Shot で 初期配置 1：99.8、10：96.5、100：96.3）。まず 10 で評価し、I 基準の値（計測マップ・結果の Excel）が気になるときだけ増やすのがよい。
- 会社の PC では性能やデータの大きさ（候補 Shot・Mark の数）で時間が変わる。「処理時間の内訳」で実際の時間を測れる。

## 既定の設定ファイル（管理者向け）

起動したときの初期設定を部署でそろえたいときは、**`alignment_estimation_defaults.json`** を起動するフォルダ（MATLAB では現在のフォルダ、exe ではショートカットの作業フォルダー）に置きます（`alignest.siteDefaults`）。

- 中身は「設定を保存…」と同じ形の JSON。**変えたい項目だけ** を書けばよい（書いていない項目はアプリの初期設定）。学習 Shot 数は `nShotsStart`・`nShotsEnd`・`nShotsStep` だけ書けば並びも合わせる。
- 起動すると「3. 実行」の記録に「既定の設定ファイルを読み込みました」と出て、「初期設定に戻す」もこの値に戻る。読めないときは警告と理由を出して、アプリの初期設定で開く。
- exe を作り直さずに初期値を変えられる。コードの初期値（`+alignest/defaultSettings.m`・`recommendedMethods.m`）を変える方法・項目ごとの初期値は [docs/defaults_guide/デフォルト設定の編集ガイド.pptx](docs/defaults_guide/デフォルト設定の編集ガイド.pptx)。

例（D 最適も比べる・外周を 130 mm・異常値を MAD で判定）：

```json
{
  "sampling": { "method": ["ioptimal", "doptimal"] },
  "evaluation": { "outerRadiusMm": 130, "outlierMethod": "mad" }
}
```

## 一時中断と再開

評価の進み具合の画面の **一時中断** を押すと、計算中の組み合わせが終わったところで止め、途中までの結果を「4. 結果一覧」「5. Wafer ごとのマップ」に出します。「3. 実行」の **続きから再開** で、残りの組み合わせだけを計算します（済んだ組み合わせ・作った学習パターンはそのまま使い、計算時間は中断の前と後を足す）。中断の後に評価の設定やデータを変えたときは再開できないので、「評価を始める」で最初から計算します（表示の設定＝Scan 方向の向き・色は変えても再開できる）。

進み具合の画面の「残り 約 ○ 分」は、今回の実行で計算した1件あたりの時間 × 残りの件数です（続きから再開・条件を足した評価では、済んだ件数を除いて計算する。以前は済んだ件数が整数の型のまま割り算され、「残り 約 1 秒」から変わらないことがあった）。

## 注意事項

- **実データ・社内データはリポジトリに入れない**（`matlab_app` 内の .xlsx・.csv はサンプルだけを登録し、それ以外は .gitignore で除外）。
- 結果を書き出すとき、同じ名前の Excel ファイルを開いていると書き出せない（閉じてからやり直す）。
- CSV は UTF-8 で保存したものを読む。Shift_JIS の CSV で Wafer ID に日本語があると文字化けすることがあるので、Excel（.xlsx）のまま読むのがよい。
- この Mac（MATLAB Compiler なし）では、スタンドアローン版の作成と .exe での動作は確認していない。MATLAB の中での画面の動作・計算・テストは確認済み。
