この一覧の見方

面内推定評価ツール（Lithography Utilities for Correction Analysis and Sampling Optimization（LUCAS））の機能を、画面のタブごとに 1 行ずつ並べた一覧です。 全 147 機能。機能仕様書（PowerPoint）の「機能の詳細」と同じ ID を使います。

列の意味

「操作・入力」は画面の欄・ボタンの名前、「結果・出力」は画面に出るもの・書き出すファイル、 「主な実装」は処理を受け持つ関数（+alignest の関数は名前だけ、+appui の画面の関数も名前だけ）です。

版の印

通常版・Pro 版 どちらの版でも使える　Pro 版だけ Pro 版だけ（8 機能） 　通常版は一部 通常版は選択肢を絞る（5 機能）

探し方

上の検索欄に言葉（空白で区切ると全部を含む行）を入れるか、版で絞り込みます。左の目次で章へ移動できます。

通常版と Pro 版の違い

同じプログラムから 2 つの版を作れます。違うのは「2. 面内推定の設定」の 3 つの設定だけで、ほかのタブ・機能は同じです。
