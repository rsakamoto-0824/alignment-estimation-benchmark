この一覧の見方

面内推定評価ツール（Lithography Utilities for Correction Analysis and Sampling Optimization（LUCAS））の通常版で使える機能を、画面のタブごとに 1 行ずつ並べた一覧です。 全 146 機能。ID は機能仕様書（PowerPoint）の「機能の詳細」と同じです（Pro 版だけの機能は載せないので、番号が飛ぶことがあります）。 最後の章に、ばらつき分解・補正の式などの計算式をまとめています。

列の意味

「操作・入力」は画面の欄・ボタンの名前、「結果・出力」は画面に出るもの・書き出すファイル、 「主な実装」は処理を受け持つ関数の名前（保守する人向け）です。

通常版

起動は runAlignmentEstimationAppStandard（窓の名前に「（通常版）」）。RT モデル・D 最適などの計測点の選び方・ Overlay の式の入力・ダークモード・凡例の位置などは Pro 版の機能です。

計算式

ばらつき分解・補正の式など、結果の数を求める式です（アプリのヘルプの技術編と同じ）。

ばらつき分解（Lot・Wafer・Shot 間）

「1. データ読込」の「ばらつき分解」（分け方「Lot・Wafer・Shot 間」）と、「3. 結果一覧」の「補正残差のばらつき分解」の計算です。 点（Mark）ごとの値の分散を、入れ子の段（上から Lot → Wafer → Shot）の分散成分に分けます（入れ子の分散分析・モーメント法。 alignest.varianceDecomposition）。

値 = 全体の平均 + Lot の効果 + Wafer の効果 + Shot の効果 + その他 全体の分散 σ2 = σLot2 + σWafer2 + σShot2 + σその他2　（分散の加法性） 段 k の平方和 SSk = Σ段 k の組 g ng (g の平均 − g の上の段の組の平均)2、　その他の平方和 = Σ点 (値 − Shot の平均)2 平均平方 MSk = SSk / 自由度k　（自由度 = 段 k の組の数 − 上の段の組の数、その他は 点の数 − Shot の数） E[MSk] = σその他2 + Σj ≥ k ckj σj2、 　ckj = [Σ段 k の組 y Σy の中の段 j の組 x nx2/ny − (同じ和を段 k − 1 の組で)] / 自由度k σその他2 = MSその他、　下の段から σk2 = (MSk − σその他2 − Σj > k ckj σj2) / ckk　（負なら 0） 段の 3σ = 3√σk2、　全体の 3σ = 3√σ2 3σ の配分 = 全体の 3σ × σk2 / σ2　（足すと全体の 3σ）、　割合 = σk2 / σ2 × 100 [%]
  • 下の段は上の段の中で分けます（Wafer はその Lot の中、Shot はその Wafer の中）。平均平方の期待値の式で下の段のばらつきを差し引くので、 平方和を点の数で割っただけの値より上の段が小さくなります。釣り合ったデータでは σShot2 = (MSShot − MSその他) / n などの、よく知られた式と同じです。
  • 3σ は足しても全体の 3σ になりません（全体の 3σ2 = 段の 3σ2 の和）。そのため図は「3σ の配分」を積み上げます。
  • その他 = Shot の中のばらつき（Mark ごとの違いと計測のばらつき）。Lot 間は Lot が 2 つ以上あるときだけ分けます。
  • 「絞り込み」で選んだ列（装置・ロット・Operation・ファイルのその他の列）の値の点だけで分けます。

ばらつき分解（成分）

「1. データ読込」の「ばらつき分解」の分け方「成分」です。Wafer ごと・軸ごとに、次の 2 段の最小二乗で回帰係数と残留を求めます （座標は mm。alignest.componentCoefficients）。

① Wafer の成分：Shot s ごとの ns 点の平均 ms を、Shot 中心 (Xs, Ys) に ns の重みで当てはめる 　X：ms = 全体 Shift + Wafer 倍率 × Xs + Wafer 回転 × Ys 　Y：ms = 全体 Shift + Wafer 倍率 × Ys + Wafer 回転 × Xs 　Wafer 成分の残留 = 3 × std点 i( es(i) )、　es = ms − (当てはめた値)　（Wafer レベルの回帰残差。点 i にはその Shot の残差を数える） ② Shot 共通の成分：点 i の値 vi からその Shot の平均を除いた値を、Shot 内の座標から Shot ごとの平均を引いた (x̃i, ỹi) に当てはめる 　X：vi − ms = Shot 倍率 × x̃i + Shot 回転 × ỹi 　Y：vi − ms = Shot 倍率 × ỹi + Shot 回転 × x̃i 　Shot 共通成分の残留 = 3 × std点 i( (vi − ms) − (当てはめた値) )　（Shot レベルの回帰残差）
  • 全体 Shift と残留の単位は nm、倍率・回転は nm/mm（= ppm。回転は µrad）。std は標本標準偏差（n − 1 で割る）。
  • 回帰に切片があるので残差の平均は 0 になり、残留の 3σ は |平均| + 3σ と同じ大きさです。
  • 点・Shot が足りず決まらない係数（例：Shot が 2 つ以下の Wafer の Wafer 倍率・回転）と、その段の残留は空欄です。
