Operating Guide · Internal Use

アライメント計測値の面内推定 検証ツール
Windows 手順書

会社の Windows PC で検証ツール（MATLAB アプリ）を動かし、実データ（Excel）で面内推定の手法を比べるための手順です。 MATLAB の中で使う方法と、MATLAB の無い PC でも使えるようにスタンドアローン版（exe）を作って配る方法を説明します。

対象: Windows 11 ＋ MATLAB R2021a 以上 exe の作成: MATLAB Compiler が必要 更新日: 2026/10/17
01

Overview

目的と対象

このツールは、Excel のアライメント計測データを読み込み、学習に使う Shot から残りの Shot の値を推定して、 推定の手法（GPR・TPS・Kriging・GAM・XY 多項式・RT モデル）を同じ条件で比べます。 使い方は次の3通りです。自分の PC の環境に合うものを選んでください。

Use A

MATLAB の中で使う

MATLAB が入っている PC。いちばん手軽です（4章 → 5章）。Toolbox は不要です。

Use B

exe を作る

MATLAB と MATLAB Compiler が入っている PC で、配るための exe（とインストーラー）を作ります（4章 → 6章）。

Use C

exe を使う

MATLAB が入っていない PC。無料の MATLAB Runtime を入れて exe を起動します（7章）。

対象者：MATLAB でフォルダを開き、コマンドウィンドウにコマンドを入力できる人。exe を使うだけなら MATLAB の知識は不要です。

02

Prerequisites

作業前の確認

  • Windows 10 または 11（64 ビット）であること。
  • （使い方 A・B）MATLAB の版が R2021a 以上であること。コマンドウィンドウで version と入力すると表示されます（このツールは R2022b で動作確認済み）。
  • （使い方 B）MATLAB Compiler が使えること。コマンドウィンドウで license('test','Compiler') と入力して 1 が返れば使えます。
  • （使い方 C）MATLAB Runtime のインストールに管理者権限が必要な場合があります。空き容量は数 GB 必要です。
  • 自作の exe を社内の PC で配布・実行してよいか、社内のソフトウェア利用ルールを確認してあること。
  • 置き場所は、日本語や空白を含まないフォルダ（例：C:\work\matlab_app）にします。ファイルの場所の問題を避けるためです。
!

実データの扱い

実データと、書き出した結果の Excel は社内の PC の中だけで扱ってください。GitHub へ上げたり、社外のサービスへ送ったりしないでください。 リポジトリに入っているサンプルデータは乱数で作った模擬データです。

04

Preparation

フォルダを置く

  1. ツール一式を手に入れる

    ブラウザで https://github.com/rsakamoto-0824/alignment-estimation-benchmark を開き、 緑の「Code」ボタン →「Download ZIP」を押します。社外のサイトに出られない場合は、作成者からフォルダを受け取ってください。

  2. matlab_app フォルダだけを置く

    ZIP を展開し、中の matlab_app フォルダを C:\work\matlab_app に置きます。 ほかのフォルダ（Python 版の評価や資料）は、このツールには不要です。

  3. 中身を確かめる

    C:\work\matlab_app の中に、runAlignmentEstimationApp.m・AlignmentEstimationApp.m・ +alignest・build・sample_data・tests・docs があれば準備完了です。

05

Use A

MATLAB で使う

  1. 現在のフォルダを matlab_app にする

    MATLAB を起動し、コマンドウィンドウに次を入力して Enter を押します。

cd C:\work\matlab_app
  1. ツールを起動する

    次を入力すると、ツールの画面が開きます（初回は画面が出るまで数十秒かかることがあります）。使い方は8章を見てください。

runAlignmentEstimationApp
  1. （初めてのときだけ）動作確認のテストを行う

    次を入力すると、自動テストが走ります（数分）。最後に「成功 89 件、失敗 0 件、未完了 0 件」と出れば、 この PC の MATLAB で正しく計算できています。 

cd C:\work\matlab_app\tests
runAllTests
cd C:\work\matlab_app
✓

テストで確かめていること

模擬データの評価に使った Python 版と同じ計算結果になること（8件）、データの読み込みと前処理（21件）、 評価・集計・書き出し・設定の保存（15件）、質的変数の設計（2件）、RBF・空間モデルの Backfitting と質的変数の選択（9件）、 画面の一連の操作（13件）、Overlay 補正の評価（6件）、平均の図・散布図・優先順のファイル（6件）、正規性検定・ANOVA が SciPy と同じ結果になること（5件）、 追加したモデルの選択肢（Matérn の ν・spherical・GAM の形状関数、4件）です。

06

Use B

exe を作る

MATLAB と MATLAB Compiler が入った Windows PC で行います。Mac では Windows 用の exe は作れません。

配り方を選ぶ

配り方作るコマンド使う PC に必要なもの向いている場合
exe だけ buildStandaloneApp 同じ版の MATLAB Runtime を別に入れる Runtime がすでに入っている PC
インストーラー（ネットから Runtime） buildStandaloneApp(makeInstaller=true) インストール時にインターネット接続 社外のサイトに出られる PC
インストーラー（Runtime 入り） buildStandaloneApp(makeInstaller=true, runtimeDelivery="installer") なし（ファイルが数 GB になる） 社外のサイトに出られない PC

作り方

  1. MATLAB Compiler があることを確かめる

    次を入力して ans = 1 と出れば使えます。0 なら 11章の「MATLAB Compiler が使えません」を見てください。

license('test','Compiler')
  1. 作成のコマンドを実行する

    C:\work\matlab_app を現在のフォルダにしてから、上の表で選んだコマンドを入力します。 次の例は、ネットから Runtime を入れるインストーラーを作る場合です。数分かかります。 

cd C:\work\matlab_app
addpath build
buildStandaloneApp(makeInstaller=true)
  1. できたファイルを確かめる

    「作成しました」と表示されれば完了です。build\output\win64\ に AlignmentEstimationApp.exe などが、 インストーラーを作った場合は build\output\win64\installer\ に AlignmentEstimationApp_Installer.exe ができます。

i

作った exe の性質

画面だけのアプリとして作ります（黒いコマンド画面は出ません）。Toolbox は使っていないので、MATLAB 本体の Runtime だけで動きます。 使う PC の MATLAB Runtime は、exe を作った MATLAB と 同じ版（例：R2022b で作ったら R2022b）が必要です。

07

Use C

exe を配る・使う

インストーラーを使う場合

  1. インストーラーを実行する

    AlignmentEstimationApp_Installer.exe を使う PC にコピーしてダブルクリックし、画面の指示に従ってインストール先を選びます。 MATLAB Runtime が入っていなければ、一緒にインストールされます（ネットから入れる形では、インターネット接続が必要です）。

  2. ツールを起動する

    インストール時に選んだインストール先にある AlignmentEstimationApp.exe（またはインストール時に作ったショートカット）から起動します。初回は画面が出るまで時間がかかることがあります。

exe だけを使う場合

  1. MATLAB Runtime を入れる

    MathWorks のサイト https://www.mathworks.com/products/compiler/matlab-runtime.html から、 exe を作った MATLAB と同じ版の MATLAB Runtime（Windows 用）を入れます。

  2. exe を起動する

    AlignmentEstimationApp.exe を任意のフォルダ（例：C:\work\app）にコピーしてダブルクリックします。

!

Windows の警告が出た場合

自作の exe は署名が無いため、Windows やウイルス対策ソフトが警告を出すことがあります。 実行してよいかは社内のルールに従い、分からなければ情報システムの担当者に確認してください。

08

How to use

画面の使い方

画面上のタブを左から順に進めます。MATLAB の中で起動しても exe で起動しても、画面は同じです。 初めてのときは、sample_data\sample_alignment.xlsx（模擬データ5枚）で一度通して試してください。 exe を配るときは、このサンプルの Excel も一緒に渡すと試しやすくなります。

画像は Mac で撮影したものです。Windows ではウィンドウの枠や文字の形が少し違いますが、配置は同じです。

8-1. データを読み込む（1. データの読み込み）

  1. 「ファイルを選ぶ…」を押す

    Excel（.xlsx）または CSV を選びます。Excel に複数のシートがあれば、「シート」で選び直せます。

  2. 列の対応を確かめる

    左の表の「ファイルの列」に、標準の項目にあたるファイルの列が入っていれば正しく対応づいています。 列名が違うときは、その欄を押して選び直します。必須の項目（Xmm・Ymm・markXmm・markYmm・measX・measY）は必ず選びます。 工程名（Operation）と装置 ID（EqpId）は任意です。あれば、工程・装置が違う計測を別々に扱い、結果の Excel にも出ます。

  3. 座標の単位を確かめる

    右の「座標の単位」の表に、列ごとの入力の単位・mm への倍率・ファイルの最大値・mm に直した値が出ます。 「確認」に「⚠」が出た列は、「入力の単位」を選び直すか、「値の大きさから単位を推定」を押します（列名が Xmm でも中身が µm なら µm）。

  4. Scan 方向が無いデータでは、付け方を選ぶ

    Direction の列が無いときは、「Scan 方向（Direction）が無い行に付ける値」で規則を選ぶと Scan 方向 1・2 を付けられます （shotNo の奇偶・市松模様・Shot 行ごと・Shot 列ごと。「付ける 1 と 2 を入れ替える」で反対にできます）。

  5. 「この対応で読み込む」を押す

    右下の「読み込み結果」に、Wafer の枚数、工程・装置、Shot 数・Mark 数、Shot の大きさ、Scan 方向の出どころ、 除いた点（未測定・半径 150 mm 以上）、まとめた重複行が出ます。

  6. 「Wafer マップ（計測値）」と「Shot レイアウト」で確かめる

    「Wafer マップ（計測値）」には、計測値の矢印の隣に X・Y 成分ごとの色の図（ヒートマップ）が出ます。灰色の枠は Shot です。 点が重なって見にくいときは「色の点の大きさ」を変えます。 「表示する Wafer・平均」で「平均：全 Wafer」「平均：EqpId = …」などを選ぶと、Wafer 間で平均した図と、Wafer 間のばらつきの共分散楕円が出ます。 「Shot レイアウト」には、左に Shot の並び（数字は shotNo、Scan 方向があれば S1・S2）、右に Shot 内の Mark の位置と番号（M の後が markNo）が出ます。

8-2. 比べ方を決める（2. 評価の設定）

  1. 学習に使う Shot の選び方を決める

    「制約付き I 最適」は前回の評価と同じ選び方です。「制約つきランダム」は同じ条件でランダムに選んで何回か繰り返します。 「手動で指定」は、shotNo を空白区切りで1行に1パターン書きます（例：1 5 9 13 17）。

  2. （計測順が決まっているとき）優先順のファイルを読み込む

    選び方を「ファイルの優先順で指定」にして「優先順のファイルを読み込む…」を押し、Shot 番号と優先度の表（Excel・CSV）を選びます。 優先度 1 の Shot は必ず学習に使い、0 の Shot は使わず（評価だけ）、残りはファイルの行の順に学習 Shot 数まで足します。

  3. 学習 Shot 数を決める

    「開始」「終了」「刻み（スイープ幅）」で決めます（例：10・40・5 で 10, 15, …, 40）。欄の下に比べる Shot 数の並びが出ます。 組み合わせに誤りがあると、欄の下に理由が出ます。

  4. 質的変数を選ぶ

    「比べる手法」の「質的変数」で、推定に使う質的変数（Scan 方向・Mark 番号・Shot 行の奇数・偶数）と、 ファイルのその他の列（標準の項目に対応づけなかった列。例：Chuck）を選びます。初期設定は Scan 方向と Mark 番号です。

  5. 比べる手法を選ぶ

    初期設定は「推奨の組み合わせ」（各系統の代表 9 手法）です。画面の下に計算回数と時間の目安が出るので、長すぎる場合は手法や Shot 数を減らします。 「設定を保存…」で設定をファイルに残し、次回「設定を読み込む…」で同じ条件に戻せます。

  6. （必要なとき）モデルの細かい選択肢を決める

    GPR のカーネルで「matern（ν を指定）」「ardmatern（ν を指定）」を選んだときは、「Matérn の ν」に値を空白区切りで入れます（例：0.75 1 2）。 Kriging のバリオグラムには spherical（球形）も選べます。GAM は「形状関数」で、X・Y、半径の項ごとにスプラインかガウス過程回帰を選べます。 RBF も TPS・Kriging と同じく、質的変数の Backfitting を選べます。

  7. （必要なとき）Overlay 補正の評価のモデルを選ぶ

    左下の「Overlay 補正の評価」で、補正モデルの Wafer 成分（Shot 中心の多項式）・Shot 共通成分（1次、または ASML・Canon・Nikon の高次式）・ Shot ごとの成分（並進・1次）を選びます。推定値で補正したときに Overlay 残差がどれだけ増えるかを評価します（すべて「なし」なら評価しません）。

  8. （必要なとき）処理時間を記録する

    1 枚あたりの推定時間で手法を選ぶときは、左下の「条件ごとの処理時間を記録する」をオンにします。 手法 × 学習パターンごとの時間が、結果一覧の指標「処理時間 [秒/枚]」と Excel の「処理時間」シートに出ます。

8-3. 実行する（3. 実行）

  1. 「評価を始める」を押す

    進み具合と残り時間の目安が出ます。途中で止めたいときは「止める」を押すと、それまでの結果が残ります。

  2. 終わったら結果一覧に切り替わる

    「記録」に、推定できなかった組み合わせや学習パターンの注意が出ます。

8-4. 結果を見る（4. 結果一覧）

上の「指標」（RMSE・MAE・R²・調整済み R²、X・Y・合計）と「集計」（平均・中央値・ワースト値・95%値）を切り替えると、下の表・グラフ・比較が変わります。 ワースト値は最も悪い Wafer の値、95%値は 95% の Wafer がそれより良い値です（誤差は大きい側、R² は小さい側）。 「結果を Excel に書き出す…」で、集計・Wafer ごとの値・学習に使った Shot・設定を1つのファイルに保存します。

中のタブ見るもの
表（手法 × 学習パターン）手法ごと・学習 Shot 数ごとの値。各列で最も良い手法に「★」と色が付きます。
グラフ学習 Shot 数による変化。右の一覧で描く手法を選べます。「エラーバー」で Wafer 間の ±1σ か平均の 95% 区間を付けられます。「横軸」を「I 基準と D 基準」にすると、学習 Shot の組の I 基準・D 基準（I 最適計画の評価指標。小さいほど良い計画）に対する推定誤差の図を2つ並べます。「グラフを画像で保存…」で PNG にできます。
基準の手法との比較上で選んだ基準の手法と、同じ Wafer・同じ学習パターンどうしで比べた差、95% 区間、基準より良かった Wafer の割合。
推定値と誤差の分布手法・学習パターン・Wafer を選んで「分析する」を押すと、残差（計測値 − 推定値）のヒストグラム、正規性検定（Shapiro–Wilk・Anderson–Darling・Jarque–Bera）、質的変数（Scan 方向・Mark 番号・Shot 行の奇偶・工程・装置・ロットと、選んだその他の列）の ANOVA が出ます。「推定値を Excel に書き出す…」で、評価点ごとの計測値・推定値・残差と検定の結果を保存します。
推定値と実測値の散布図手法・学習パターン・Wafer を選んで「描く」を押すと、実測値と推定値の散布図（X・Y）が出ます。相関係数・回帰直線を表示し、点の色を LotID・EqpId・Operation・Scan 方向・Mark 番号・その他の列で分けられます。

8-5. Wafer ごとに見る（5. Wafer ごとのマップ）

Wafer・学習パターン・手法を選ぶと、評価した Shot の計測値・推定値・残差（計測値 − 推定値）を並べて表示します。 灰色の四角は学習に使った Mark、細い灰色の枠は Shot です。「表示」で矢印と色（X・Y）を切り替えられます。 「Wafer・平均」で LotID・EqpId・Operation ごとや全 Wafer の平均を選ぶと、Wafer 間で平均した図と共分散楕円が出ます。 「図の内容」を「Overlay 補正」にすると、実測値で補正した残差・推定値で補正した残差・推定による変化（両者の差）を並べ、下の行に |平均|+3σ を出します。 色のときは「色の点の大きさ」で点の大きさを変えられます。下の行に、その組み合わせの指標が出ます。

i

評価の考え方

実データには真の値が無いので、学習しなかった Shot の 計測値 と推定値を比べます。 計測値には計測ノイズが含まれるため、誤差は模擬データでの評価より少し大きく出ます。手法どうしの比べ方は同じです。

09

Data format

読み込むデータの形

1行目が項目名、2行目からデータの表です。項目名はアライメント計測テーブルの標準に合わせます（違っていても画面で対応づけられます）。

項目名意味必須無いとき
Operation工程名任意工程が違えば別の計測として扱う
EqpId装置 ID任意装置が違えば別の計測として扱う
LotIDロット ID任意ロットが違えば別の計測として扱う
Waferウェハ ID任意全行を1枚とみなす
DateTime測定日時任意同じ Wafer でも日時が違えば別の計測として扱う
shotNoショット番号任意座標から番号を付ける（上の行から左→右）
DirectionScan 方向（1 または 2）任意選んだ規則で付ける（「付けない」なら Scan 方向を質的変数・制約に使わない）
Xmm, Ymmショット中心の座標 [mm]必須—
Radiusショット中心の半径 [mm]任意あれば Xmm・Ymm からの計算値と合うか確かめる
markNoショット内のマーク番号任意マーク座標の組ごとに番号を付ける
markXmm, markYmmショット中心から見たマーク座標 [mm]必須—
measX, measYマークの測定値 [nm]必須—
StsX, StsYステータス（0 = 有効、−1 = 未測定）任意測定値が空でなければ有効

読み込むときに自動で行うこと

  • 座標は、「座標の単位」で選んだ単位から mm に変換します（測定値 measX・measY は nm のまま）。
  • 解析座標は x = Xmm + markXmm、y = Ymm + markYmm。半径 150 mm 以上の点は除きます（画面の「有効半径」で変更可）。
  • X には StsX = 0 の measX、Y には StsY = 0 の measY だけを使います。未測定を 0 として扱いません。
  • Wafer・DateTime・Xmm・Ymm・markXmm・markYmm が同じ行は重複とみなし、測定値を X・Y それぞれ平均します。

Troubleshooting

困ったとき

「MATLAB Compiler が使えません」と出る

その PC の MATLAB に MATLAB Compiler のライセンスまたはインストールがありません。ver と入力して一覧に「MATLAB Compiler」があるか確かめ、 無ければ MATLAB の管理者に相談してください。exe を作らなくても、5章のとおり MATLAB の中では使えます。

exe が起動しない、またはすぐ閉じる

MATLAB Runtime が入っていないか、版が違う可能性があります。exe を作った MATLAB と同じ版の Runtime が入っているか確かめてください。 インストーラーで入れ直すのが確実です。

「ファイルを読み込めませんでした」と出る

ファイルを Excel で開いたままにしていないか、1行目が項目名になっているかを確かめてください。 読めるのは .xlsx・.xlsm・.xls・.csv です。

「必須の項目が対応づけられていません」と出る

「列の対応」の表で、メッセージに書かれた項目の「ファイルの列」を選んでから、もう一度「この対応で読み込む」を押してください。

「Direction（Scan方向）は 1 か 2 にしてください」と出る

Direction の列に 1・2 以外の値があります。対応づけた列が正しいか確かめてください。Scan 方向を使わない場合は、Direction の対応を「（なし）」にします。

記録に「学習パターンを作れませんでした」「制約を満たす組が見つからず」と出る

学習 Shot 数が Wafer の Shot 数に対して多すぎるか、制約が厳しすぎます。学習 Shot 数を減らすか、 「許容幅」を大きくする、または「4象限」「Scan 方向」の制約を外してください。

計算に時間がかかりすぎる

「2. 評価の設定」の下の目安を見ながら、比べる手法（「推奨の組み合わせ」が目安）や学習 Shot 数を減らしてください。 「すべて選ぶ」（245 手法）は数時間かかることがあります。I 最適の「交換法の初期配置の数」を減らすと、学習パターンを作る時間が短くなります。

結果を Excel に書き出せない

同じ名前のファイルを Excel で開いていると書き出せません。閉じてからもう一度書き出すか、別の名前で保存してください。

CSV の Wafer ID が文字化けする

CSV は UTF-8 で保存したものを読みます。Excel（.xlsx）のまま読み込むのが確実です。

テストが失敗した

失敗したテストの名前と、表示されたメッセージを控えて、ツールの管理者に連絡してください。

i

解決しない場合

ツールの管理者へ、発生日時・操作した画面・表示されたメッセージを連絡してください。 実データそのものは送らず、必要なら列名や行数だけを伝えてください。
