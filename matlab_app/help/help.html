ヘルプ：用語・補正の式・カーネル

このアプリで使う主な用語と、推定の手法・カーネル・Overlay 補正の式をまとめています。式の記号は画面と Excel の書き出しと同じです。 座標は Wafer 半径（150 mm）で割った値（x, y, r = √(x² + y²)）を使います（Overlay 補正の Shot 内の座標を除く）。

使い方の流れ

  1. 1. データの読み込み：計測ファイルを読み、列の対応・座標の単位・Scan 方向を確かめる。Wafer マップ・Shot レイアウト・Shot 重ね合わせで中身を見る。
  2. 2. 評価の設定：学習 Shot の選び方（I 最適・D 最適・ランダム・人の選択・優先順・Mark 単位）と数、制約、比べる手法、Overlay 補正のモデルを決める。
  3. 3. 実行：計測マップで学習に使う Shot（Mark）を確かめてから「評価を始める」。後から「条件を追加して評価」で手法・学習 Shot 数を足せる。
  4. 4. 結果一覧：表・グラフ・基準の手法との比較・計測配置の比較・誤差の分布（ANOVA・箱ひげ図）・散布図・分布の比較・処理時間の内訳。
  5. 5. Wafer ごとのマップ：計測値・推定値・残差（または Overlay 補正）を Wafer 上で見る。条件を並べて比べられる。

画面の色はメニューの「表示」でライトモード・ダークモードを選べます（次に開いたときも同じ色）。

用語

学習 Shot の選び方

用語意味
学習 Shot・学習点計測する（推定の学習に使う）Shot と、その Shot の有効な Mark。残りの Shot の Mark を推定する。
評価点学習しなかった Shot（Mark 単位の計画では、学習しなかった Mark）の有効な Mark。推定値と計測値を比べて誤差を求める。実データには真の値が無いので、計測値を真の値の代わりに使う（計測ノイズの分だけ誤差は大きく出る）。
学習パターンどの Shot（Mark）を学習に使うかの1つの組。例：「I最適 20 Shot」。結果の表の列は学習パターンの列（ランダムのくり返しは1列にまとめる）。
計測率候補 Shot（計測値のある Shot）に対する学習 Shot の割合 [%]。Wafer ごとに 候補 Shot 数 × 計測率 を四捨五入した数を使う。
I 最適計画基準モデル（XY 多項式、既定は5次・21項）の予測分散の平均が最も小さくなる組。I 基準 tr(M−1) を小さくする（M = 選んだ点の情報行列）。
D 最適計画同じ基準モデルで det(M) を最も大きくする組（係数の推定のばらつきの体積を小さくする）。D 基準 det(M)−1/p を小さくする。
交換法最適計画を探す方法。初めの組から「1つ外して1つ入れる」交換のうち基準が最も良くなるものを、良くならなくなるまでくり返す。初めの組（初期配置）を変えて何回か行い、最も良い組を使う。時間は初期配置の数にほぼ比例する。
制約I 最適・D 最適・ランダムで、同心円（Shot 中心の半径 [mm] の区切り）・4象限・Scan 方向の区画ごとの Shot 数を、全体の割合 × 選ぶ数 ± 許容幅にそろえる。
必ず計測する Shot（拡張 I 最適計画）指定した shotNo・最外周の Shot を先に学習に入れ、残りを最適計画で選ぶ。交換法は必ず計測する Shot を外さない。
最外周の Shot上下左右のどこかに隣の Shot が無い Shot（Shot 中心の座標から数えた行・列で判断）。
Mark 単位の I 最適計画全 Shot を1点以上計測し、計測する Mark を I 最適で選ぶ。計測する Mark の数 = 1 Shot あたりの Mark 数 × 候補 Shot 数。Mark 番号ごとの数は、全計測での割合 × 計測する数 ± 許容幅にそろえる（例：4 Mark なら各 25%）。評価点は計測しなかった Mark。
人の選択（手動）人が決めた計測配置。Excel（shotNo と、パターンごとの 1 = 計測する・0 = しない の列。計測マップの Excel と同じ形）から読み込める。I 最適・D 最適と同じ評価の中で比べられる。
I 基準・D 基準・I 効率・D 効率選んだ組の良さ（小さいほど良い計画）。全候補を計測すると I 基準 = 項数 p、D 基準 = 1。I 効率 = p / I 基準、D 効率 = 1 / D 基準（全計測に対する割合、1 に近いほど良い）。

評価の指標

用語意味
残差計測値 − 推定値（評価点）。
RMSE残差の二乗平均の平方根 √(Σe²/n) [nm]。X・Y・X と Y の合計（XY）。外周（Mark の半径が外周とみなす半径 [mm] 以上）と内側も出す。
MAE残差の絶対値の平均 Σ|e|/n [nm]。
R²1 − Σ(計測値 − 推定値)² / Σ(計測値 − 平均)²。1 に近いほど良い。
平均値・中央値に対する改善学習点の平均値（中央値）をそのまま推定値にした場合の RMSE と比べた改善量 [nm] と改善率 [%]（大きいほど良い）。
ワースト値・95%値Wafer 間の集計。ワースト値は最も悪い Wafer の値、95%値は 95% の Wafer がそれより良い値（Excel の PERCENTILE.INC と同じ補間）。Wafer ごとのマップでは、点の大きさ |v| と X・Y の絶対値のワースト値・95%値も出す。
評価点の絞り込み半径・shotNo・Scan 方向・最外周の条件に合う評価点だけで指標を計算し直す（推定はやり直さない）。
異常値の除外（nσ・MAD）学習点のうち、中心から n × ばらつき を超えて離れた Mark を X・Y の両方の学習データから除く。nσ：中心 = 平均、ばらつき = 標準偏差 σ。MAD：中心 = 中央値、ばらつき = 1.4826 × MAD（MAD = 中央値からの差の絶対値の中央値。正規分布では σ と同じ大きさで、外れ値に引きずられにくい）。

質的変数

用語意味
質的変数数ではなく区分を表す変数。Scan 方向（1・2）・Mark 番号・Shot 行の奇偶・ファイルのその他の列。X 成分と Y 成分で別に選べる。
Scan 方向露光装置が Shot を走査する向き（Direction の列、または規則で付けた 1・2）。計測マップ・Wafer マップでは緑 ▲ = 1、紫 ▼ = 2。
Shot 行の奇偶Shot 中心の Y 座標で上から数えた行が奇数か偶数か。
Slot の偶奇Wafer ID のハイフンの後の整数（例：LOT123-05 → Slot 5 → 奇数）。平均の図・ANOVA・箱ひげ図・散布図で、偶数と奇数で傾向が違うかを見る。
効果コード（固定効果）水準ごとのずれを平均の基底関数に入れ、ほかの係数と同時に推定する（GPR の「同時推定」）。
変量効果（加法カーネル）水準ごとのずれを確率変数とみなし、カーネルに項 τ²δ を足す（下の「質的変数の項」）。ずれは 0 の方へ縮んで推定される。
交互作用2つの質的変数の組み合わせごとのずれ（例：Scan 方向 × Mark 番号）。
Backfitting空間の推定と質的変数の効果の推定を、交互に当てはめ直して収束させる方法。

統計・図

用語意味
正規性検定残差が正規分布から外れているか。Shapiro–Wilk（5000 点以下）・Anderson–Darling・Jarque–Bera。p < 0.05 なら外れていると判定。
ANOVA・η²質的変数の水準で残差の平均が違うかの F 検定。η² は水準の違いで説明できる残差のばらつきの割合。「ほかの変数で調整」はほかの質的変数を入れた主効果モデル（Type II）。
箱ひげ図箱は四分位範囲、中の線は中央値、ひげは箱から 1.5 × 四分位範囲まで、外の点は外れ値、◆ は平均。
JS ダイバージェンス2つの分布の違い（0 = 同じ、1 = 重なりなし。底 2）。共通の区間のヒストグラムの割合 P・Q で、M = (P + Q)/2、JS = KL(P‖M)/2 + KL(Q‖M)/2。
共分散楕円座標ごとの Wafer 間（Shot 間）の X・Y のばらつきと相関を表す楕円。色は相関係数の絶対値 |r|。
同心円の区切り線同心円の制約の区切りの半径（Shot 中心の半径 [mm]）を橙の一点鎖線で描いたもの。

推定の手法

手法式・考え方
GPR（ガウス過程回帰）
f(z) ~ GP(m(z), k(z, z′))、 y = f(z) + ε、ε ~ N(0, σn2)
平均 m(z) は定数（質的変数を固定効果にするときは効果コードを加える）。カーネルの長さスケール ℓ・σf・σn・τ は、対数周辺尤度を最大にして求める。説明変数 z は (x, y) または (x, y, r)。
TPS（薄板スプライン）
f(z) = c0 + cTz + Σi wi φ(‖z − zi‖)、 φ(r) = r2 log r
平滑化の強さ λ は一般化交差検証（GCV）で選ぶ。
RBF（ガウス型）
f(z) = c0 + cTz + Σi wi exp(−‖z − zi‖2 / (2ℓ2))
ℓ は候補（0.05〜1.6）から、λ とともに GCV で選ぶ。
Kriging（通常・Universal）バリオグラム γ(d)（下の表）を経験バリオグラムに当てはめ、重み付きの線形予測をする。通常は平均（ドリフト）が定数、Universal はドリフトを説明変数の1次式 [1, z]（z = (x, y) または (x, y, r)）にし、ドリフトを除いた残差で経験バリオグラムを求める。
GAM（一般化加法モデル）
y = β0 + s(x, y) [+ s(r)] + 質的変数の効果 + ε
形状関数 s はスプライン（3次 B スプライン＋2階差分の罰則、P-spline）かガウス過程回帰（節点での低ランク近似、下の「GAM のガウス過程」）。罰則の強さと長さスケールは REML で選ぶ。
XY 多項式
f(x, y) = Σa + b ≤ N cab xa yb
最小二乗（特異値分解の擬似逆行列、相対の打ち切り 10−10）。
RT モデル（次数 K）変位を半径方向 R と接線方向 T に分け、R = ρ·M(x, y)、T = ρ·Θ(x, y)。局所倍率 M・局所回転 Θ を Zernike 多項式（動径次数 n ≤ K）で展開し、並進2項・非対称倍率・直交度の4項を加える。X・Y を同時に当てはめる。
Fringe Zernike
f(ρ, θ) = Σj = 1(k+1)² cj Zj(ρ, θ)
次数 k の Fringe Zernike 多項式（下の「Fringe Zernike」）の最小二乗。X・Y は別々に当てはめる。

カーネル（すべて）

GPR のカーネル

距離 r は説明変数の差を長さスケールで割ったもの。等方のカーネルは r = ‖z − z′‖ / ℓ（長さスケール1つ）、ARD（ard…）は説明変数ごとに長さスケールを持つ： r2 = Σd (zd − z′d)2 / ℓd2　（d = x, y, r） カーネルは k(z, z′) = σf2 g(r)。g は下の表のとおり（MATLAB の fitrgp と同じ10種類と、ν を指定する Matérn）。

exp(−r)
Matérn ν = 1/2 と同じ。最も粗い（連続だが微分できない）。
squaredexponential・ardsquaredexponential
exp(−r2/2)
最も滑らか（何回でも微分できる）。

質的変数の項（GPR の質的変数の扱い）

δf(z, z′) は、2点の質的変数 f（Scan 方向 s・Mark 番号 m・Shot 行の奇偶・その他の列）の水準が同じなら 1、違えば 0。

扱いカーネル・平均
使わない
k = σf2 g(r)、 平均 = 定数
同時推定（基底関数）
k = σf2 g(r)、 平均 = β0 + Σ 効果コード × β
水準ごとのずれを固定効果として同時に推定。
同時推定＋交互作用上の平均に、2つの質的変数の効果コードの積の列を加える。
BackfittingGPR の当てはめと質的変数の効果の推定を交互にくり返す。
加法カーネル
k = σf2 g(r) + Σf τf2 δf(z, z′)
例：k = σf2g(r) + τs2δs + τm2δm（変量効果）。
加法カーネル＋交互作用
k = σf2 g(r) + Σf τf2 δf + Σf<h τfh2 δf δh
選んだ質的変数のすべての2つの組（3つ以上の組は入れない）。
混合（Mark 変量／他は固定）Mark 番号は加法カーネルの項 τm2δm、それ以外の質的変数は効果コード（固定効果）。「混合＋交互作用」は交互作用の項も加える。

GAM のガウス過程の形状関数

形状関数をガウス過程回帰にした項は、節点 κk でのカーネルによる低ランクの近似： s(z) = 線形部分 + Σk bk k(z, κk)、 罰則 λ bT K(κ, κ) b カーネル k は等方で σf = 1 の上の g(r)（exponential・squaredexponential・matern32・matern52・rationalquadratic（α = 1 に固定）・matern（ν を指定））。長さスケールは候補（0.15・0.3・0.6）から REML で選ぶ。

Overlay 補正の式

推定値で補正量を求めたとき、実際の値で求めた補正と比べて Overlay 残差がどれだけ増えるかを評価します（「2. 評価の設定」の「Overlay 補正の評価」）。

補正モデル

補正量(Mark) = Wafer 成分(X, Y) + Shot 共通成分(x, y) + Shot ごとの成分Shot(x, y)

X・Y は Shot 中心の座標（Wafer 半径で割る）、x・y は Shot 内の Mark の座標（markXmm・markYmm、Shot 中心から）。dx（X 成分）・dy（Y 成分）を別々に最小二乗で当てはめます。 成分どうしで重なる項（例：Wafer 成分の定数と k1）や、Mark が少なくて決まらない項があっても、当てはめた補正量は一つに決まります（列空間への射影）。

成分選択式
Wafer 成分1次（並進・倍率・回転・直交度）
dx = a0 + a1X + a2Y、 dy = b0 + b1X + b2Y
N 次（2〜5次）
dx = Σi+j≤N aij XiYj、 dy = Σi+j≤N bij XiYj
式を入力入力した dx・dy の式（x・y が Shot 中心の座標）
Shot 共通成分1次（k1〜k6）
dx = k1 + k3·x + k5·y、 dy = k2 + k4·y + k6·x
全 Shot で同じ係数。
式を入力入力した dx・dy の式（x・y が Shot 内の座標）。全 Shot で同じ係数。
Shot ごとの成分並進（k1・k2）
dx = k1Shot、 dy = k2Shot
1次（k1〜k6）
dx = k1Shot + k3Shot·x + k5Shot·y、 dy = k2Shot + k4Shot·y + k6Shot·x
式を入力入力した dx・dy の式（x・y が Shot 内の座標）。係数を Shot ごとに別々に求める。

A：全 Mark の計測値、 E：学習点は計測値・評価点は推定値（実際の運用で補正に使う値） 実測値で補正した残差 RA = A − 補正量(A) 推定値で補正した残差 RE = A − 補正量(E) 推定による変化 D = RE − RA = 補正量(A) − 補正量(E) 代表値 |平均| + 3σ（X・Y 別、σ は不偏標準偏差）、 増加量 = (RE の値) − (RA の値)

式の書き方（「式を入力」）

  • 項を +（または −）でつなぎ、各項は係数と x・y のべきの積：k1 + k3*x + k5*y + k7*x^2 + k9*x*y
  • 係数の名前（k1 など）は何でもよく、係数の値は最小二乗で求めるので、名前・符号は補正量に影響しません。
  • べきは x^2・x²・x³ と書けます（9 乗まで）。xy は x*y と同じ。全角の文字や「dx =」も読めます。
  • かっこ、2x のような * の省略、x1 のような書き方は使えません。
