機能編：画面の使い方

タブごとの使い方と、画面の欄・図・表の意味をまとめています。式と計算の方法は「技術編」にあります。

使い方の流れ

  • 1. データの読み込み：計測ファイルを読み、座標の定義（Shot 中心＋Shot 内の位置／絶対座標だけ）と推定する値（X・Y 成分／膜厚・線幅などの1変数）を選び、列の対応・座標の単位・Scan 方向を確かめる。Wafer マップ・Shot レイアウト・Shot 重ね合わせで中身を見る。
  • 2. 評価の設定：学習 Shot の選び方（I 最適・D 最適・ランダム・Excel ファイルで指定・Mark 単位）と数、制約、比べる手法（初期設定は GPR だけ）、Overlay 補正のモデルを決める。
  • 3. 実行：計測マップで学習に使う Shot（Mark）を確かめてから「評価を始める」。後から「条件を追加して評価」で手法・学習 Shot 数を足せる。
  • 4. 結果一覧：表・グラフ・基準の手法との比較・計測配置の比較・誤差の分布（ANOVA・箱ひげ図）・散布図・分布の比較・処理時間の内訳。
  • 5. Wafer ごとのマップ：計測値・推定値・残差（または Overlay 補正）を Wafer 上で見る。条件を並べて比べられる。
  • 6. 未知の座標の推定：計測していない座標（新しい Mark の位置・Wafer 上の任意の点）の推定値を求める。点は Excel・CSV から読むか、画面で入力・作成する。外挿の点は知らせる（下）。
  • 7. Shot高次補正：計測値・未知の座標の推定値・Excel の値で、Shot 高次補正（ASML・Canon・Nikon・カスタムの式）の k パラメータを求め、Shot ごとの1次（k1〜k6）の補正と比べて効果を評価する。外周の Shot だけ別の式にでき、内周・外周に分けて評価する。くくり・λ・回帰・項の組み合わせを変えた補正をまとめて比べ、2つの条件の Wafer を並べて改善・悪化した Shot を見る。Wafer ごとの k パラメータ・残差、残差のヒストグラムも見られる（下）。
  • 8. Mark配置の最適化：Shot 高次補正の計測 Mark の配置を、Mark の数（最低数から1点ずつ）ごとに I 最適計画で選び、選んだ配置で補正した制御残差を I 効率と比べる。必ず計測する Mark を指定でき、実測値の無い座標は乱数 Shotで評価する（下）。

推定誤差で Overlay 残差がどれだけ増えるかを評価します。結果は「4. 結果一覧」の指標「OVL …」と、「5. Wafer ごとのマップ」の「Overlay 補正」で見られます。すべて「なし」なら評価しません。「6. 未知の座標の推定」の「補正のモデル」でも同じ設定を変えられます。式は技術編にあります。

欄内容

式の書き方（「式を入力」）

  • 項を +（または −）でつなぎ、各項は係数と x・y のべきの積：k1 + k3*x + k5*y + k7*x^2 + k9*x*y
  • 係数の名前（k1 など）は何でもよく、係数の値は最小二乗で求めるので、名前・符号は補正量に影響しません。
  • べきは x^2・x²・x³ と書けます（9 乗まで）。xy は x*y と同じ。全角の文字や「dx =」も読めます。
  • かっこ、2x のような * の省略、x1 のような書き方は使えません。

4. 結果一覧

上の「指標」「集計」（Wafer 間の集計）「基準の手法」はタブ共通です。評価点は半径・Shot の条件で絞り込んで計算し直せます。

タブ見方
表手法 × 学習パターン。各列で最も良い手法に「★」を付け、背景も色づけします。集計の「ワースト値」は最も悪い Wafer の値、「95%値」は 95% の Wafer がそれより良い値です（誤差は大きい側、R²・改善率は小さい側）。
グラフ学習 Shot 数（学習パターン）に対する指標、または I 基準と D 基準を描きます。描く手法は Ctrl・Shift で複数選べます。エラーバーの ±1σ は Wafer 間のばらつき、95% 区間は平均の区間です。
基準の手法との比較同じ Wafer・同じ学習パターンどうしで比べた差の平均、その 95% 区間、基準より良かった Wafer の割合。差は誤差の指標では割合（負なら基準より良い）、それ以外は差（正なら基準より良い）です。
計測配置の比較「2. 評価の設定」で選び方を2つ以上選んで評価すると、選び方ごとの線（Excel で指定したパターンは点）で比べられます。横軸は計測する Mark の数・学習 Shot 数・D 効率・I 効率（全計測に対する割合）から選びます。I 基準・D 基準は小さいほど良い計画です（Wafer の平均）。エラーバーは ± 標準偏差（Wafer 間のばらつき）・95% 信頼区間・Wafer の最小〜最大です。
推定値と誤差の分布手法は複数選ぶと並べて比べます。残差 = 計測値 − 推定値（評価点）。p 値 < 0.05 なら、正規分布から外れている（ANOVA は水準で残差の平均が違う）と判断します。点数が多いと小さなずれでも p 値が小さくなるので、ヒストグラムと合わせて見てください。
残差の箱ひげ図「推定値と誤差の分布」で「分析する」を押した残差を描きます。箱は四分位範囲、中の線は中央値、ひげは箱から 1.5 × 四分位範囲まで、外の点は外れ値、◆ は平均です（ANOVA は水準の平均の違いを調べます）。
推定値と実測値の散布図評価点（学習しなかった Shot の有効な Mark）の実測値と推定値。破線は y = x、赤い線は回帰直線（推定値 = a + b·実測値）、r は相関係数です。
残差と説明変数評価点の残差（計測値 − 推定値）と説明変数の散布図。赤い線は回帰直線、黒い線は区間ごとの平均（曲がった傾向）です。r は相関係数で、0 に近いほどその説明変数の傾向は残っていません。p 値 < 0.05 なら相関があると判断しますが、点が多いと小さな相関でも p 値が小さくなるので、r の大きさと図を合わせて見てください。
分布の比較左は Wafer 全面・学習データ・予測対象（学習しなかった Shot の有効な Mark）の計測値、右は予測対象の実測値と推定値です。ヒストグラムは4つに共通の区間の割合です。JS ダイバージェンスは分布の一致性で、0 なら同じ、1 なら重なりなしです。
処理時間の内訳選んだ Wafer・学習パターン・手法の1回分の処理（学習パターンの作成 → 異常値の判定 → 推定の準備 → 学習 → 推論 → 評価指標・Overlay 補正の評価）を、評価と同じ関数で測ります（評価の結果は変えません）。学習と推論は、全評価点を推定した時間と評価点を1点にした時間の差を推論とします。評価では学習パターンを同じ配置の Wafer・手法で使い回すので、評価全体に占める作成の割合はこれより小さくなります。

Excel ファイルで指定人が決めた計測配置を Excel・CSV で渡す（以前の「手動・人の選択」と「ファイルの優先順」をまとめたもの）。1行目が見出しで、shotNo の列（markNo の列もあれば Mark 単位：1行が1つの Mark）と、名前を見出しにした列を並べる。1・0 だけの列はパターン（1 の Shot・Mark を計測する）。1・2・3… の列（または見出しに「優先」「prior」を含む列）は優先順（1 = 必ず計測、2・3… = その次に計測する順、空欄 = 番号の後に行の順、0 = 計測しない）で、学習 Shot 数（計測率。Mark 単位は 1 Shot あたりの Mark 数・計測率）ごとに先頭から使う。計測マップの Excel（「計測マップ_Mark」シートがあればそれ）もそのまま読める。I 最適・D 最適と同じ評価の中で比べられる。

計画の基準

用語意味
I 最適計画基準モデル（XY 多項式、既定は5次・21項）の予測分散の平均が最も小さくなる組。I 基準 tr(M−1) を小さくする（M = 選んだ点の情報行列）。
D 最適計画同じ基準モデルで det(M) を最も大きくする組（係数の推定のばらつきの体積を小さくする）。D 基準 det(M)−1/p を小さくする。
交換法最適計画を探す方法。初めの組から「1つ外して1つ入れる」交換のうち基準が最も良くなるものを、良くならなくなるまでくり返す。初めの組（初期配置）を変えて何回か行い、最も良い組を使う。時間は初期配置の数にほぼ比例する。
I 基準・D 基準・I 効率・D 効率選んだ組の良さ（小さいほど良い計画）。全候補を計測すると I 基準 = 項数 p、D 基準 = 1。I 効率 = p / I 基準、D 効率 = 1 / D 基準（全計測に対する割合、1 に近いほど良い）。「計測配置の比較」では D 効率・I 効率 [%] を横軸にできる。
エラーバー（計測配置の比較）評価点ごとの Wafer の値のばらつき。標準偏差 s（Wafer 間）、95% 信頼区間 平均 ± 1.96 s/√n（正規近似）、Wafer の最小〜最大から選ぶ。

指標・検定・質的変数

用語意味
異常値の除外（nσ・MAD）学習点のうち、中心から n × ばらつき を超えて離れた Mark を X・Y の両方の学習データから除く。nσ：中心 = 平均、ばらつき = 標準偏差 σ。MAD：中心 = 中央値、ばらつき = 1.4826 × MAD（MAD = 中央値からの差の絶対値の中央値。正規分布では σ と同じ大きさで、外れ値に引きずられにくい）。
効果コード（固定効果）水準ごとのずれを平均の基底関数に入れ、ほかの係数と同時に推定する（GPR の「同時推定」）。
変量効果（加法カーネル）水準ごとのずれを確率変数とみなし、カーネルに項 τ²δ を足す（下の「質的変数の項」）。ずれは 0 の方へ縮んで推定される。
Backfitting空間の推定と質的変数の効果の推定を、交互に当てはめ直して収束させる方法（TPS・RBF・Kriging・Fringe Zernike）。
正規性検定残差が正規分布から外れているか。Shapiro–Wilk（3〜5000 点）・Anderson–Darling（8 点以上）・Jarque–Bera。p < 0.05 なら外れていると判定。計算しなかったときは W・A² の欄に理由（例：「— 6000 点（5000 点超）」）を出す。点数は選んだ Wafer の評価点の合計なので、Wafer を1枚に絞ると計算できることがある。
ANOVA・η²質的変数の水準で残差の平均が違うかの F 検定。η² は水準の違いで説明できる残差のばらつきの割合。「ほかの変数で調整」はほかの質的変数を入れた主効果モデル（Type II）。
残差と説明変数の相関評価点の残差と説明変数（座標・半径・方位角・Shot 内の位置）の相関係数 r（Pearson）。t = r√((n−2)/(1−r²)) の t 検定の p 値。r が 0 に近ければ、その説明変数の傾向は残っていない。区間ごとの平均で曲がった傾向も見る。
JS ダイバージェンス2つの分布の違い（0 = 同じ、1 = 重なりなし。底 2）。共通の区間のヒストグラムの割合 P・Q で、M = (P + Q)/2、JS = KL(P‖M)/2 + KL(Q‖M)/2。

手法式・考え方
GPR（ガウス過程回帰）
f(z) ~ GP(m(z), k(z, z′))、 y = f(z) + ε、ε ~ N(0, σn2)
平均 m(z) は定数（質的変数を固定効果にするときは効果コードを加える）。カーネルの長さスケール ℓ・σf・σn・τ は、対数周辺尤度を最大にして求める。説明変数 z は (x, y) または (x, y, r)。

f(z) = c0 + cTz + Σi wi φ(‖z − zi‖)、 φ(r) = r2 log r
平滑化の強さ λ は、一般化交差検証（GCV）で選ぶ、なし（λ を固有値の平均の 10−12 倍にして学習点を通る面）、指定した log10 λ（固有値の平均に対する倍率）から選ぶ。
RBF（ガウス型）
f(z) = c0 + cTz + Σi wi exp(−‖z − zi‖2 / (2ℓ2))
ℓ は候補（0.05〜1.6）から、λ とともに GCV で選ぶ。

GAM（一般化加法モデル）
y = β0 + s(x, y) [+ s(r)] + 質的変数の効果 + ε
形状関数 s はスプライン（3次 B スプライン＋2階差分の罰則、P-spline）かガウス過程回帰（節点での低ランク近似、下の「GAM のガウス過程」）。罰則の強さと長さスケールは REML で選ぶ。
XY 多項式
f(x, y) = Σa + b ≤ N cab xa yb
最小二乗（特異値分解の擬似逆行列、相対の打ち切り 10−10）。

f(ρ, θ) = Σj = 1(k+1)² cj Zj(ρ, θ) [+ 質的変数の効果]
次数 k の Fringe Zernike 多項式（下の「Fringe Zernike」）の最小二乗。X・Y は別々に当てはめる。質的変数を Backfitting で足すこともできる（Zernike の当てはめ行列 H = Z(ZTZ)+ZT を空間成分にして、効果と交互に推定する）。

Wafer RT

値(Mark) = RT(X, Y) + Σ使う項 kj·xmyn　　X = Xc / Wafer 半径、Y = Yc / Wafer 半径 RT の dx = tx + a·X + b·Y + Σi (Mi·X − Θi·Y)·Zi(X, Y) RT の dy = ty − a·Y + b·X + Σi (Mi·Y + Θi·X)·Zi(X, Y)　　Zi：動径次数 n ≤ K の Zernike 多項式
  • 式は推定の手法の RT モデルと同じです。tx・ty は並進、a は非対称倍率、b は直交度、Mi は局所倍率、Θi は局所回転の係数です。項の数は 4 + (K+1)(K+2) です（K = 5 で 46 項）。
  • Shot 中心の座標で当てはめるので、RT の補正量はその Shot の並進になります（Wafer 成分と同じです）。
  • Wafer ごとに X・Y を1組の係数で求めて先に引き、残りを補正の式で求めます。X・Y 別の補正の式とは一緒に求めません。
  • 正則化はかけません。X・Y の損失関数が同じならその損失関数（Huber の c は X の値）、違うときは最小二乗で求めます。
  • 「外周だけ」のときは、RT は外周の Shot の点だけで求めます。Wafer 成分は内周の Shot の点だけに効きます。k の組は「補正のくくり」のとおりです。
  • 補正のくくりが「Shot ごと」のときは、Shot ごとの k1・k2 が Shot 中心の座標の関数をすべて含むので、補正量・残差は Wafer RT なしと同じです。Shot ごとの k1・k2 が RT の分を除いた値になります。
  • Shot の配置で決まらない RT の項は 0 にします（書き出しの「補正値」のメモ）。

VIF と項の選び方

VIFj = 1 / (1 − Rj2)　（Rj2：項 j を、ほかの項（定数を含む）で回帰したときの決定係数）

VIF は選んだ Wafer のすべての点の Shot 内の座標で求めます（∞ はその配置では決まらない項）。「VIF で選ぶ」は、式のすべての項から始めて、VIF がしきい値以上の高次項があれば、その中で次数の最も高い項（同じ次数なら VIF の最も大きい項）を外し、VIF を求め直します。しきい値以上が1次の項だけなら、高次項の中で VIF の最も大きい項を外します。低い次数の項を残します（多項式の階層を保つ）。

回帰の式

最小二乗：(1/2n) Σ ri2 + 罰則 Huber ：(1/n) Σ s2 ρc(ri/s) + 罰則　（重み wi = min(1, c·s/|ri|)） LAD ：(1/n) Σ s|ri| + 罰則　（重み wi = s / max(|ri|, 0.1·s)） 罰則 L2：(λ/2) Σ選んだ次数の項 θj2　　L1：λ Σ選んだ次数の項 |θj| s = 1.4826 × MAD（残差の中央値からの絶対偏差の中央値） c → 0 の Huber は LAD と同じ目的関数になるので、スイープの c = 0 は LAD で計算します

損失関数・c・正則化の種類・λ・かける次数は dx の式と dy の式で別に決められます。2つの式は別に解くので、片方の設定はもう片方の結果を変えません。

  • 項（列）を平均0・標準偏差1にそろえてから解きます（θ はそろえた係数）。正則化が項の単位・座標の桁によらず同じ強さで効くようにするためです。
  • 正則化は「なし・L2・L1」から選びます。L2 は係数を小さくし、点が少ない・項が似ているときの係数のばらつきを抑えます。L1 は効かない項の係数をちょうど 0 にします（使う項を選ぶのに近い）。項が直交するときは、L2 の係数は最小二乗の 1/(1 + λ)、L1 の係数は最小二乗の係数を λ だけ 0 に近づけた値（λ より小さい係数は 0）です。
  • かける次数は1次〜6次から選べます（初期値は2次〜6次。1次は k3〜k6 の倍率・回転）。定数（k1・k2）と Wafer 成分にはかけません。λ > 0 なら、かけた次数の項は点が少ない Shot でも決まります。
  • L1 は、罰則をかけない列を最小二乗で消してから、かける列を座標降下法（1項ずつ軟しきい値で更新）で解きます。Huber・LAD と組み合わせるときは、重みを変えるたびに解き直します。
  • Huber・LAD は、残差の大きい点ほど当てはめへの影響（重み）を小さくした重み付き最小二乗を、重みを変えながら解き直します（IRLS）。尺度 s は最初の20回だけ求め直して固定します。点の数が項の数以下の組では重みを使いません。
  • 外れ値とみなした点：重みが 0.5 未満になった点（影響を半分未満に弱めた点）。Huber は |残差| が尺度 s の 2c 倍（c = 1.345 なら約 2.7 倍）、LAD は 2 倍を超えた点です（s は残差の MAD × 1.4826。正規分布なら標準偏差に当たる）。雑音だけのデータでは 1% ほど、最小二乗では 0 です。重みが少しだけ下がった点（Huber で |残差| が c × s を少し超えた点など）は数えません。

R² = 1 − SSE / SST　　SSE = Σ 残差²、SST = Σ (値 − 値の平均)² 自由度調整済 R² = 1 − (SSE / (n − p)) / (SST / (n − 1))　　n：点の数、p：回帰の自由度
  • p は回帰のハット行列の対角の和です。最小二乗では求めた係数の数（k の組の数 × 使う項の数 + Wafer 成分の項の数）と同じ、L2 では項の数より小さい値（有効自由度）、L1 では係数が 0 でない項の数です。Shot ごとで Wafer 成分を先に引くときは、Wafer 成分の項の数も足します。Wafer RT を使うときは、RT の回帰のハット行列の対角も X・Y の行ごとに足します。

Mark 配置の計算

補正の式の使う項で、選んだ Mark で最小二乗で当てはめたときの、評価する Mark の位置での予測の分散の平均（I 基準）を最も小さくする配置を選びます。dx の式と dy の式の I 基準を足して選びます。VIF は候補の Mark の位置（それぞれ1点）で求めます。I 基準は最小二乗の式で、ロバスト回帰・正則化は制御残差を求めるときに使います。

I(S) = Σ式 trace(MS−1 W)　　MS = FS' FS（選んだ Mark の項の値）、W = F' F / N（評価する Mark の平均） D(S) = Σ式 det(MS)−1/p　（p：項の数） I 効率 = 計測できる Mark をすべて計測したときの I ÷ その配置の I　（100% = 計測できる Mark をすべて計測） D 効率 = 計測できる Mark をすべて計測したときの D ÷ その配置の D

評価する Mark：実測値で評価するときは、どの Shot にも値の無い Mark を除きます（必ず計測する Mark は残します）。計測しない Mark は、W（評価する位置）と制御残差には入れますが、配置には選びません。

交換法（修正 Fedorov 法）：選んだ Mark を1つずつ、I が最も小さくなる候補と入れ替え、よくならなくなるまで繰り返します。1つ前の数の配置に1点足した配置・Mark を1つずつ足した配置・乱数で選んだ配置から始め、最もよい配置を使います。必ず計測する Mark は入れ替えません。

乱数 Shot：dx・dy それぞれ、大きさを入れた次数（0〜7次）の項 ua·vb（u = x / X の最大、v = y / Y の最大）から、形ごとに項を乱数で選び（項ごとに確率 0.5。1つも選ばれなければ1項）、次数ごとの大きさ [nm] を標準偏差とする正規乱数の重みを掛けて足します。乱数は形ごとに別の流れで作るので、同じ種なら、形の数・飛び値を変えても同じ番号の形は同じです。

制御残差：最小二乗で正則化が L2 かなしのときは、配置ごとに1度求めた係数の式を、値がそろった Shot にまとめて使います（Shot ごとに当てはめたときと同じ値）。Shot スタックマップの楕円は、Mark の位置ごとの Shot（形）間の制御残差の共分散から求めます。
